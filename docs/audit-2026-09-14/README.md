## 재현 방법과 범위

[표본 충분성 재현 ZIP](추가검토_표본충분성_재현.zip)을 별도 작업 폴더에 풀고, 압축을 푼 폴더에서 다음 명령을 실행한다. Python 표준 라이브러리만 사용하며 묶음 안의 보존 원자료를 읽는다. `source_snapshot`의 실험 스크립트는 근거 보존용이므로 실행하지 않는다.

```powershell
python -B summarize_sample_size.py
python -B test_sample_size.py
```

이 재현은 원자료 해시, 표본 충분성 계산과 관련 검사에 대한 것이다. QUIC 성능 실험을 다시 실행하는 명령이 아니다. ZIP에는 원자료·소스 사본, 출처·검사 결과와 요약기가 들어 있다.

출처 점검 코드는 `--runtime`, `--manifest`, `--started`, `--output-dir`가 필요하고, `--repo`로 대조할 사본을 지정한다. 출력 위치는 측정 정본과 지정한 저장소 밖이어야 한다. 당시 수정 목록과 전체 시각별 스냅숏은 이 11개 파일에 모두 동봉하지 않았으므로, 출처 점검 JSON의 과거 판정을 이 폴더만으로 전부 재실행할 수는 없다. 현재 상태를 다시 읽으면 당시와 다른 완료 수가 나올 수 있다. 저장된 점검은 실행기의 단계 지문을 기록한 것이며 실행 프로세스의 환경을 독립 재구성한 검사가 아니다.

정책 비교 문서에 언급한 별도 작업 폴더의 설계 검사 코드·증거 파일도 이 묶음의 동봉 범위에 포함되지 않는다. 해당 문서의 가상 예제와 후속 설계를 새 네트워크 측정 결과로 해석하지 않는다.
