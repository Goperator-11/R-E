# v3.2 followup validation

2026년 10월 3일의 후속 검증이다. 자동 후보의 패리티 예산, 실패 시 학습·목적지 캐시 상태 보존, 캐시 입력 검사와 빌드 소스 격리를 수정했다. 합성 적응 벤치도 추가했다. 새 네트워크 성능은 측정하지 않았다.

Python 검사 109개와 하위 검사 367개, Go 검사 101개, vet·race·빌드가 통과했다. WSL 빌더 격리 검사 2개도 통과했다. 근거는 [Python 검사](python-tests.txt), [Go 검사](go-tests.txt), [빌드](go-build.txt), [race 검사](go-race.txt), [빌더 격리 검사](build-staging-tests.txt)에 있다.

[Go·Python 대조](go-python-parity.json)는 원시 모형 5,400개, 결정 11,720개와 궤적 90,000단계에서 통과했다. 선택 결과와 학습·감시 상태가 정확히 일치했고 계산 비용 차이는 0이었다. 현재 Go 소스·바이너리와 기준 자료의 지문도 일치했다.

[합성 적응 요약](adaptation-summary.json)은 조건 3개와 시드 31·32·33의 비교다. 관측별 행만 생략하고 조건·구간별 통계와 출처 해시를 보존했다. 큰 인증서의 시드 33에서는 위험률 전이를 막은 비교군이 full보다 기대 비용이 1.141114 ms 작았다. 인증서 6,000 B 조건에서는 세 시드의 두 비교 차이가 모두 0이었다. 자신의 비용 모형을 쓴 개발 사례이며 실제 HCT, 예측 정확도나 H4 적응 기여의 확증이 아니다.

과거 저널 1,000행의 개발 재생은 관측마다 위험률 예측 전이를 한 번 적용했으며 새 결정은 실행하지 않았다. v3.1의 보호 파일 88개는 수정 전후 해시가 같다. 과거 H1 통과, H2·H3 실패와 H4 기여 미확인 판정은 원래 자료의 판정으로 남는다.

[검증 기록](verification.json), [소스 해시](sources_sha256.json), [후속 수정 보고서](report.md)에 변경과 한계를 기록했다. 실행 명령은 [개발본 README](../../../README.md)에 있다. 이전 검증은 [상위 색인](../README.md)에서 확인한다.
