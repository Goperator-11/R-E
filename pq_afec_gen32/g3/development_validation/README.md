# v3.2 development validation

2026년 10월 3일에 검사한 `v3.2-dev` 개발본이다. 학습을 생략한 관측의 위험률 전이, 중앙값 잔차 감시, 입력·캐시 검증과 과거 실행기의 격리를 수정했다. 새 네트워크 성능은 측정하지 않았다.

Python 회귀검사 97개와 하위 검사 293개, Go 검사 94개가 통과했다. Go vet, 빌드와 race 검사도 통과했다. 실행 근거는 [Python 검사](python-tests.txt), [Go 검사](go-tests.txt), [빌드](go-build.txt), [race 검사](go-race.txt)에 있다.

[Go·Python 대조](go-python-parity.json)는 기준 원시 모형 2,800개, 결정 6,720개, 10,000단계 궤적 다섯 개와 추가 난수 모형 2,600개, 결정 5,000개, 10,000단계 궤적 네 개에서 통과했다. 결정과 궤적 상태가 일치했고 모형 비용 차이는 0이었다. 바이너리와 현재 Go 소스의 지문도 일치했다. 이는 구현 일치 검사이며, 실제 지연 예측 정확도나 성능 개선의 증거로 쓰지 않는다.

과거 v3.1 저널 1000행은 기록된 행동과 관측을 사용해 개발 재생했다. 관측마다 위험률 예측을 한 번 적용했으며 새 결정은 실행하지 않았다. 원자료와 재생 행은 게시하지 않고 요약만 [검증 기록](verification.json)에 남겼다.

v3.1 봉인 소스 31개와 결과·저널·봉인을 포함한 보호 파일 88개는 수정 전후 해시가 같다. 과거 v3.1의 H1 통과, H2·H3 실패, H4 적응 기여 미확인 판정은 원래 측정의 판정으로 남는다. v3.2의 실제 성능을 확인하려면 새 보류 조건과 봉인된 측정 프로토콜이 필요하다.

게시 소스 해시는 [sources_sha256.json](sources_sha256.json)에 있다. 검사 명령과 지원 범위는 [개발본 README](../../README.md)에 기록했다.
