# M1 고정 행동 표의 독립 검사

`validate_m1_fixed.py`는 고정 행동 보고기의 계산 함수를 import하지 않는다. 가족 계획에 묶인 MC 결과를 읽고 SciPy의 정규분포 역생존함수로 공동 99% 오차를 계산한다. 원래 보고기는 표준 라이브러리의 역누적분포함수를 쓴다. 두 계산의 277행동 가족 분위수는 별도 시험으로 대조한다.

전체 64행과 32개 hold-off 차이, 두 손실률의 16행동 최솟값을 다시 계산한다. 최솟값 구간의 양 끝은 각 행동 구간의 하한 최솟값과 상한 최솟값이다. 점추정 최선 행동 하나만의 구간으로 대체하지 않는다. 어느 행동의 MC 오차가 미정의이면 점추정이 나빠 보이는 행동이어도 최솟값 구간은 미확정이다.

독립 주 보고 검사가 통과한 기록과 같은 가족 해시를 요구한다. 각 결과의 원자료 계보와 파일 해시를 확인한 뒤 행·열·순서·수치·진단 표시를 대조한다. 새 채택 기준이나 전역 최적이라는 표시가 생기면 거부한다. 이 검사는 이미 고정한 산식을 검산하며 표본·seed·행동 목록·채택 기준을 바꾸지 않는다.
