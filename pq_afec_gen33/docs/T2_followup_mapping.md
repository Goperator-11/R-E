# T2 후속 과제 연결 정정

TASKS.md의 M4는 이미 Retry·토큰 입력, lead·delta 축소, 뒤 패리티와 서버 복호 지원 입력을 맡는다. 반복42에서 추가한 E21의 토큰 정책 부분은 M4와 겹친다. 별도 대기 과제로 중복 실행하지 않고 M4의 하위 점검 목록으로 통합한다.

M4를 수행할 때 E21에 적은 토큰 보유와 서버 수락 구분, 무효 토큰 fallback, full handshake와 TLS 재개 관측의 캐시 분리도 읽고 검증한다. T2의 auto·auto3 거부는 해당 정책 관문 전까지 유지한다. 상태 파일의 E21은 skipped로 표시하며 이유는 M4 통합이다. 성능 측정은 기존 X4, 서버 신호·dup 비교 입력은 M4와 E20의 연결을 따른다.

T2_result.md와 계약의 E21 표기는 이 하위 점검 목록을 가리킨다. 이 정정은 구현과 검증 결과를 바꾸지 않는다.
