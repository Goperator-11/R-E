15%의 기본 참조가 ±10 ms 안에 들어가지만, 2%의5건에는 모든 고정 프로필이 기준을 벗어난다. 과거 재보호 모형도 같은 한계를 가진다. 낮은 손실률의 표본 수와 직접 실패 라벨 부재를 기록하며, 전체 기준 통과나 현재 와이어의 정확성을 주장하지 않는다.

첫 실패에서 복구에 못 쓴 뒤 parity는 스택 credit에서 제외했다. 원본이 모두 없어도 선행 parity credit은 남긴다. 재전송 뒤 parity는 복원한 원본의 바이트로 대체하고, 수신한 물리 바이트를 넘는 credit을 허용하지 않는다. 이전 비행 원본 구간을 이월하지만 이전 암호문 심벌은 새 비행의 FEC에 합치지 않는다.

두 번째 실패 뒤 손실 없이 끝내는 근사 질량을 따로 공개했다. 이 값은 무한 재시도 기대값이나 꼬리 상한이 아니다. ACK·응답 바이트, 서버의 이미 쓴 증폭 예산, RTT 갱신과 손실 타이머 재무장, RTT200의 선행 PTO 탐침은 아직 모델링하지 않았다. RFC 유도 표본 PTO 배수3을 실측으로 표시하지 않았다.

알려진 입력의72문맥에서 기존 모형과 새 참조가 고른 행동은 모두 같았다. 전체 행동의 점수·종료 질량·재전송 바이트는 J3_diagnostic_full_v1/result.json에 있고, 선택 표는 J3_bench.md에 있다. 학습·재평가·감시를 실행한 결과가 아니며 W1 비열등을 대신하지 않는다.

J3는 partial이다. 다음 단계에서 별도 전송 세계의 T6 모양·재전송 원본 범위·타이머를 검증한다. 동결 W1과 활성 L1 상태4·Go는 유지한다. 처리 시간·두 번째 응답 손실은 J1·J4·O3의 미완료 범위와 구분한다.
