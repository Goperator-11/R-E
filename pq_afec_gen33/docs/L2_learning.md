# L2 목적지별 등급 잡음 추정

2026-11-02 정정: L2 후보(상태 5)는 채택되지 않았다(`docs/L2_disposition.md`). 지금 활성 정책 v3.3.1-dev(상태 11)에서 이 문서가 고치려던 HCT 3등급(범주) 우도는 C1 회신을 본 목적지에서 쓸 수 없는 회신, 곧 회신이 없거나(`source_none`) 잘렸거나(`truncated`) 비어 있는(`sent=0`, `empty`) 연결에만, 결정 문맥이 있을 때 쓰고(`padfec3/learn3.py` `_observe_c1`), C1 회신이 확인되기 전 목적지는 v3.2-dev와 같은 이진 우도·결정을 쓴다. 근거 `docs/V33FIX_policy.md`.

2026-10-31 반복 17에서 성능 실행 전에 정한 설계다. L1의 세 등급과 경계 여유 3 ms를 유지하고, 고정 EPS를 목적지별 Beta 근사로 바꾼다. 사전은 Beta(1,999), 평균 0.001이다. 강도 1000은 카드에 없는 구현 기본값이며 과거 자료에서 추정한 값이 아니다. 결과를 보고 사전 강도나 경계를 탐색하지 않는다.

관측한 등급 z의 잠재 모형 질량을 q라 하면 우도는 `(1-epsilon)*q + epsilon*(1-q)/2`다. epsilon은 다른 두 등급으로 바뀌는 총확률이다. 감사의 이진 사건 비율이나 균등 오염 비율과 같지 않다.

## 결정과 관측 순서

재평가를 포함한 최종 행동을 고른 뒤, 아직 현재 연결 결과를 보기 전에 목적지 상태에 snapshot 하나를 저장한다. 행동, 결정 번호, 관측 수, 문맥, 제공 RTT, 처리 여유, 두 경계, EPS 사전 a/b와 hazard 전이 뒤의 예측 등급 질량을 포함한다. 예측은 순수 계산이며 손실 상태에 hazard를 적용하지 않는다. 새 결정은 아직 소비하지 않은 snapshot을 대체한다. 한 목적지에서 순서대로 결정하고 관측하는 API이며 동시 연결의 순서 연결은 이 작업의 범위 밖이다.

관측 때 snapshot의 결정 번호·관측 수·행동·전송 설정·EPS 상태를 확인한다. 정상 snapshot의 결정 당시 문맥과 경계로 grade와 categorical 손실 우도를 계산한다. 현재 연결에서 갱신된 RTT로 과거 경계를 바꾸지 않는다. 문맥이 없던 cold 결정은 관측값으로 문맥을 채우지 않는다. snapshot이 없거나 일치하지 않는 직접 호출은 관측 시점 문맥을 쓰되 EPS 보정을 건너뛰고 이유를 남긴다. 손상된 snapshot과 비유한 Beta 상태는 전체 관측을 거부한다.

현재 손실 우도에는 관측 전 EPS 평균을 쓴다. C1/ACK의 완전 도착 계수가 있으면 기존 데이터그램 우도만 한 번 적용하며 EPS를 섞지 않는다. 그 뒤 현재 grade와 결정 전 q로 EPS를 갱신하고 다음 연결부터 새 평균을 사용한다. snapshot은 유효 관측 한 번 뒤 소비한다. 실패도 grade 2로 포함하며 C1 회신 유무로 EPS 표본을 제한하지 않는다. 문맥·snapshot이 유효한 전체 연결을 분모로 사용해 C1 회신 선택에 따른 추가 제외를 만들지 않는다.

## Beta 근사

관측 전 a/b와 q가 고정됐다고 가정한다. `e=a/(a+b)`, `r=(1-q)/2`, `D=(1-e)*q+e*r`이며 오류 책임값은 `rho=e*r/D`다. 한 관측의 정확한 EPS 주변 사후는 `(1-rho)*Beta(a,b+1)+rho*Beta(a+1,b)`다. 이 혼합의 평균과 분산을 보존하는 Beta 하나로 투영한다. 분수 계수를 단순히 더하는 방식은 사용하지 않는다.

분산은 두 성분 내부 분산과 성분 사이 분산을 양수 항으로 더한다. q=0과 q=1은 공액 경계, q=1/3은 무정보이므로 상태를 정확히 유지한다. a/b와 합·모멘트·투영 결과는 양의 유한수여야 한다. 실패를 임의의 강한 사전으로 치환하지 않는다. 강도는 증가만 하는 값이 아니며 EPS를 사후에 임의로 자르지 않는다.

손실과 EPS를 독립 주변분포로 유지하는 반복 투영은 근사다. 한 관측 뒤 둘의 상관은 보존하지 않는다. C1 도착과 HCT도 독립이 아니므로 전체 공동 사후를 계산했다는 뜻이 아니다. C1 경로의 p에는 도착 우도만 쓰고, EPS에는 관측 전 HCT 예측을 쓰는 보조 보정으로 한정한다. EPS는 모형·RTT·S 오차와 진짜 역방향 손실을 흡수할 수 있다. 실제 라벨 오류율의 식별된 추정값으로 부르지 않는다. world_class, 참 p·RTT·S, ideal 수신 정답은 EPS 입력으로 쓰지 않는다.

## 상태와 검증 범위

STATE_VERSION은 5로 올리고 1~4 상태는 거부한다. 목적지마다 a/b와 갱신·건너뜀 수, 이유별 분모, pending snapshot을 직렬화한다. 관측 입력 오류는 기존 원자적 rollback을 유지한다. Go는 G1에서 같은 연산 순서로 옮긴다.

독립 유리수 적분과 부동소수점 경계, 무정보·공액 조건, 최종 행동 snapshot, 관측 전후 EPS 순서, 현재 RTT 혼입 방지, C1 손실 갱신 불변, cold·누락·불일치·손상 snapshot과 구상태 거부를 검사한다. 역사 자료는 A0의 행과 원래 cutoff를 유지한 6777행 비교를 재사용하고 실제 왕복 수 정답과 구별한다.

새 W1 실행은 L1 snapshot과 보고서를 보존한 별도 판본에서 같은 세계·seed·참조를 사용한다. C1을 주 비교로 유지하고 none의 B1·B2 및 B6 악화를 별도 기록한다. L 공통의 0.5 ms 비열등과 개선 조건을 바꾸지 않는다. 감시 벌점·재평가·손실 사전·S 표본 선택·비용 모형은 각각 L3/L4/L5/J 과제에 남는다.
