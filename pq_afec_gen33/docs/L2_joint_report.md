# L2 공동 행동 평가

`bench_learning_l2_report.py`는 완료된 L1 원자료와 L2 수집 자료를 같은 W1 프로토콜에 연결한다. L1 900실행, L2 900실행, 고정 EPS 600실행과 v31·v32 600실행을 구분한다. 15셀과 20seed가 각 역할에 모두 있어야 하며, 빠진 실행이나 중복 실행은 거부한다.

분석 전에는 전체 수집의 완료 기록과 75개 하위 실행의 시작·종료 기록, 명령, 로그 SHA를 대조한다. 개별 결과 파일이 먼저 생겼더라도 전체 수집 완료 기록이 없으면 원자료를 읽지 않는다. 기존 L1의 행동 목록도 원자료에서 다시 만들어 기존 파일과 대조한다.

모든 역할이 선택한 행동의 합집합을 하나의 MC 작업군으로 고정한다. N131072와 seed850001은 사전 계획을 따른다. 기존 L1 정밀화의 구간을 섞지 않는다. 기대 차이는 seed별로 직접 빼고, 두 정책에 같은 행동이 쓰인 비율만큼 공통 MC 오차를 상쇄한다. 최적 행동 선택 오차는 직접 정책 비교에서 상쇄되지만 절대 후회에는 남는다.

150그룹과 210개의 셀별 짝비교를 저장한다. L2와 L1의 직접 차이, L2와 고정 EPS의 차이, 고정 EPS와 L1의 차이를 구분한다. 주 비교는 none·C1의 L1 대비 비열등과 C1의 v31·v32 대비 비열등이다. 셀을 합쳐 실패를 상쇄하지 않는다. ideal과 고정 EPS는 진단이며, 결과를 보고 후보를 바꾸지 않는다.

EPS 표는 실패 연결을 포함한 전체 관측 수, 갱신 대상, 건너뛴 이유와 seed별 최종·마지막200관측 평균을 보존한다. EPS는 근사 모형의 유효 잡음 매개변수다. 실제 잘못된 라벨의 비율을 식별한 값으로 해석하지 않는다.

`l2_joint_driver_v1.py`는 계획 생성, 계산, 보고를 각각 한 번 실행한다. 실행 전후 소스와 입력 SHA를 비교하고 각 단계의 시작·종료 기록을 남긴다. 실패한 계산의 보고, 완료 기록의 변경, 기존 출력 덮어쓰기를 거부한다. 이 도구는 대화의 반복 과제를 선택하거나 진행하지 않는다.

합성 자료 검사와 기존 보고 검사 38개 및 하위 검사47개가 통과했다. 전체 3000실행 구성, 행동 합집합, 직접 비교의 공통 MC 상쇄, 미확정·실패 보존, 실패 연결의 EPS 분모, 단계별 증거 변경과 실패 뒤 보고 거부를 검사했다. 실제 개발 성능 판정은 전체 계산과 별도 산술 검증 뒤에 기록한다.
