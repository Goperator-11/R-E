## 1. 서로 다른 두 행동의 관측 분산 0 해소 규칙 Z1

대상은 `oracle.evaluate_action` 계열 행동 표 가운데 action과 reference_action이 다르고, 짝 차이의 표본분산이 1e-20 이하(`zero_observed_variance`)라서 `gap_half_width_ms`가 null인 (문맥, 행동) 쌍이다. 이런 쌍에는 예외 없이 이 규칙을 적용한다. 결과를 보고 셀이나 후보를 골라 적용하지 않는다.

1. 같은 문맥(혼합 문맥이면 같은 혼합 명세)에서 행동 a와 기준 r을 서로 다른 새 seed로 따로 평가한다. 새 seed는 지금까지 어떤 oracle, bench, 진단에서도 seed로 쓰지 않은 값이다. 이번 재판정의 배정은 J6 c6000 p0.08 문맥 (12,0,4) 대 (7,0,4)에 a=860001, r=860002, p0.01 문맥 (12,0,2) 대 (7,0,2)에 a=860003, r=860004다. 나중에 적용할 때는 860005부터 두 개씩 차례로 배정한다.
2. 각 행동을 connection 0부터 N-1까지 평가한다. N=131072다. 두 표본은 공통 난수를 쓰지 않는 비짝(unpaired) 표본이다. 세계 소스, worldparams, 혼합 추첨 방식은 원래 표와 같게 둔다. 실패 연결도 평균과 분산에 그대로 넣는다.
3. 차이 추정은 d = mean_a - mean_r, 표준오차는 se = sqrt(var_a/N + var_r/N)이다. var는 n-1 분모 표본분산이다.
4. 신뢰수준과 가족 보정은 동결 보고 규칙(`g3/v33/bench_reporting_rules.json`의 MC 99%)과 원래 행동 표의 `evaluation_family_size` F를 그대로 쓴다. z = Φ^-1(1 - 0.01/(2F))다. J6 행동 표는 F=116이다.
5. 차이 구간은 [d - z·se, d + z·se]다.
6. 직접 비교(`bench_report.direct_comparison`)와 기대 후회 계산에서는 원래 짝 점추정 g(seed 850001 표의 `mean_gap_ms`)를 seed 추정에 그대로 쓴다. MC 반폭만 h = max(d + z·se - g, g - (d - z·se))로 채운다. 그러면 [g - h, g + h]가 5의 비짝 구간을 포함한다.
7. var_a나 var_r 가운데 하나라도 1e-20 이하이면 null을 유지하고 미확정으로 둔다.
8. 이 규칙은 MC 표본을 늘리는 정밀화가 아니다. 원래 표의 N과 seed, 판정 문턱(0.5 ms 비열등, C1 감소 상한 0 미만), seed 95% Student t 구간, 모든 셀 통과 규칙은 바꾸지 않는다.
9. 결과가 채택 조건을 만족해도 이 문서만으로 활성 정책을 바꾸지 않는다. 정책 반영은 별도 과제로 한다.

### 2.1 채택 판정의 배포 경로 (C-E7)

채택 조건은 none을 포함한 모든 배포 경로(none, c1)가 v32 대비 15셀 모두 비열등(조정 상한 0.5 ms 이하)인 것이다. 주 비교 하나(D14의 c1)만으로 none 경로의 악화를 진단으로 내리지 않는다. ideal은 특권 진단으로 남긴다. v3.3.1-dev 설계처럼 c1_seen이 거짓인 목적지에서 v3.2-dev와 바이트 단위로 같은 결정을 내리는 후보는 none 경로를 구조 동치로 보고하되, 동치는 결정 기록 재생으로 확인한 뒤에만 쓴다. 참고로 이 규칙을 J6에 적용하면 none 대 v32 B6이 +6.364139 [5.121544, 7.606734]로 실패하므로 채택되지 않는다(L1에서 물려받은 악화, `g3/v33/V33FIX_J6_rejudge_v1.json`의 forward_rule).

### 2.2 MC 정밀화 (C-E2, D-E5)

MC 표본을 늘리는 정밀화는 계획에 미리 적은 경우에만 하고, 그 경우에 걸린 모든 후보와 모든 행동 표에 똑같이 적용한다. 정밀화 seed는 원래 seed의 앞부분을 다시 쓰지 않는 새 값이다. 결과를 본 뒤 한 후보의 경계 셀만 다시 계산하지 않는다. L1의 채택 근거는 "사후 정밀화 조건부"로 표기한다. N=131072에서 C1 대 v32 B6 조정 상한 0.573320(미확정)이었고, 결과를 본 뒤 seed 850001 앞부분을 포함한 N=1048576으로 0.479549(통과)가 됐다(`g3/v33/L1_benchmark.json`, `g3/v33/L1_benchmark_precision_v1.json`, C-E2 원문). 확증하려면 새 validation seed와 미리 정한 N으로 다시 평가한다. 1절 Z1은 정밀화가 아니라 미정의 경계를 채우는 규칙이며 같은 원칙(미리 등록, 모든 해당 쌍에 적용)을 따른다.

### 2.3 셀 수 보정 (C-E8)

"모든 셀 통과"로 채택하는 판정(intersection-union)은 보정하지 않는다. 반대로 셀 하나를 근거로 하는 주장, 곧 "어느 셀 fail"이라는 라벨과 "C1 감소 셀이 하나 이상"이라는 조건에는 같은 비교에 속한 셀 수 m으로 Bonferroni 보정한 seed 구간을 쓴다. 두 쪽 구간의 임계값은 Student t(df=19)의 1 - 0.05/(2m) 분위수다. m은 비교 하나의 셀 수(W1 15셀)이며, 두 모드를 묶어 판정하면 30이다. MC 경계는 기존대로 더한다. 보정 전 라벨도 함께 남긴다.

영분산은 seed 수준과 MC 수준에서 같은 원칙으로 다룬다. 원칙은 "출처를 설명하거나 독립 표본으로 다시 잰다"이다. seed 수준의 표준편차 0은 seed마다 두 정책의 행동 가중 차이가 같을 때만 받아들이며, 이 경우 남는 불확실성은 MC 경계에 있으므로 MC 경계가 유한해야 한다. 행동 가중이 seed마다 다른데 seed 추정이 우연히 같으면 받아들이지 않고 미확정으로 둔다. MC 수준의 서로 다른 행동 영분산은 1절 Z1로 다시 잰다.

4. 20 seed 전체에서 정책별 고착 진입 seed 수를 표로 만들고, B8 셀의 HCT 차이가 고착 seed 몇 개로 설명되는지 분해한다.
5. 고착이 학습층의 흡수 상태라면 none 경로 학습층의 결함으로 따로 등록하고, B8 none 셀은 고착 확률(seed 단위 이항)과 비고착 조건부 HCT 차이의 두 지표로 나눠 다시 설계한다. 이 재설계의 seed 수는 별도 검정력 계산으로 정한다.
