# O2 숨긴 업링크 세계 진단 계획

이 단계는 정책 비용 모형의 minimax 선택을 동결 독립 사건 세계로 옮기는 개발 진단이다. 활성 L1의 학습 성능이나 채택 관문을 대신하지 않는다. 참조는 각 손실 단계의 p, 인증서 크기, RTT를 알고 u만 모른다. 실제 관측에서 이 정보가 주어진다는 주장은 하지 않는다.

W1의 B1·B2·B11·B12_c6000·B12_c12000을 사용한다. 기존 손실 단계 순서·각450연결·seed31~50은 그대로 두고, 각 시나리오의 실제 업링크만 U={0,2,5,10,20,50}으로 교차한다. 총600개 seed 실행,810000개 연결 문맥이다. 각 문맥에서 서로 다른 행동을 같은 seed·연결 번호의 공통 난수로 평가한다. worldsim.py·worldparams.json의 W1 지문을 검증하고 모든 기능·매개변수를 유지한다.

팔은 unknown_u_nominal, unknown_u_race, known_u_model, fixed_trailing4다. 처음 두 팔은 실제u를 받지 않으며 각각 U와 U×q배율{0.5,1,2}의 minimax 참조다. known_u_model은 같은 후보 집합의 참u·명목q 비용 최솟값을 고른다. fixed_trailing4는 (0,0,4)다. 알려진 u 비교팔도 세계 oracle은 아니다. S는 검증자와 같은 cert+s0_at(base_bin)이며, 실제 세계가 만든 서버 송신량을 미리 읽지 않는다. 모델 후보를 세계 결과로 선택하지 않는다.

주 비교는 두 unknown 팔 각각과 두 비교팔의 차이다. 같은 시나리오에서 반복되는 p 단계는 seed 안에서 합쳐 낮은 손실900개·높은 손실450개로 요약한다. 시나리오5개×실제u6개×p2개×unknown2개×비교팔2개로240대조다. seed 단위 평균 차이에95% Student t 구간과 family confidence95%의 Bonferroni 구간을 낸다. 차이는 unknown HCT에서 비교팔 HCT를 뺀 ms/연결이다.

보정 구간의 하한이6.5 ms를 넘으면 그 참조에 세계 후회 상한6.5 ms의 반례가 있는 것으로 기록한다. 최적 행동의 비용은 비교 행동 비용보다 크지 않으므로, 비교 행동 대비 손해만으로도 최적 행동 대비 후회의 하한을 얻는다. 반례를 못 찾았다고 통과를 선언하지 않는다. 전체 행동 oracle과 실제 학습층·전체 W1 비열등은 별도다. 서로 다른 행동에서 관측 분산0이면 구간을 미정의로 두며, 같은 행동이면 구조적 차이0으로 기록한다. 정규성·seed 표본20개의 한계를 기록한다.

전체 표본을 실행하며 중간 결과로 seed·길이·문턱·후보를 바꾸지 않는다. smoke는 각 단계 첫4연결,각u·시나리오의 seed31만 사용하고 원래 연결 번호0~3,450~453,900~903을 보존한다. dry-run은 출처·계획만 검사한다. 코드·계획·검사를 커밋한 뒤 전체 실행한다. 실행별 gzip 원자료·SHA-256·요약과 시작/종료 출처 지문을 남기고, 첫 연결의 사건 trace를 단계별로 보존한다.

추정기는 이 진단 팔에 연결하지 않는다. 반복43의 합성 수렴표와 실제 적격 관측이 없는 상태를 그대로 기록한다. 추정값을 정책에 쓰는 채택 후보는 관측 출처·경로 안정성·ACK 귀속을 갖춘 뒤 별도로 평가한다. 6.503042445 ms였던 모형 최대값의 반올림을 이유로6.5 기준을 완화하지 않는다.
