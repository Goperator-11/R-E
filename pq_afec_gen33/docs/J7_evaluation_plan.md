# J7 개발 평가 계획

결과를 보기 전에 비교 범위를 고정한다. 기준 정책은739e6d3의 L1 상태4이며, 기존 L1_v1 사본과 패키지 전체의 바이트가 같은지 확인했다. 후보는 J7의46 B 상수와1452 B 후보 상한을 적용한 상태4다. 학습 우도·사전·관측기는 바꾸지 않는다.

두 정책을 기존39 B 세계와 새46 B 세계에서 각각 실행한다. 새 세계는 각 시나리오의 fec.parity_overhead_base만46으로 덮어쓴다. 원래 worldsim.py·worldparams.json·bench_protocol.json은 보존한다. 새 값은 카드가 정한 와이어 계약에서 왔으며 정책 성능에 맞춰 고른 값이 아니다. CID·커널·실제 QUIC를 재현하는 세계라는 뜻은 아니다.

네 조합 모두 W1의15셀, seed31~50, 전체 연결 수·손실 일정·혼합 추첨·RTT 규칙을 그대로 쓴다. none·c1·ideal을 모두 수집한다. 관측기는 기존 L1의 수동 관측 계약을 그대로 사용한다. ideal은 진단이며 C1 결과를 대신하지 않는다. B0와(0,3,1) 고정 행동은 해당 세계에서 다시 생성한다. 세계가 다른 원자료나 참조값을 같은 세계의 짝비교에 섞지 않는다.

주 비교는 각 세계 안에서 J7에서 L1을 뺀 기대 비용 차이다. none·c1의 각15셀을 모두 판정한다. seed 단위95% 구간과 전체 행동 가족의 공통 MC 오차를 합쳐 상한0.5 ms/연결 이하를 요구한다. C1에서 보정 상한0 미만인 감소 셀이 있어야 개선 조건을 충족한다. 기존 W1의 기대 비용 판정을 실현 HCT 차이로 대체하지 않는다. 실현 HCT·바이트·p 편향은 함께 보고하되 진단으로 표시한다. 한 셀이라도 실패하거나 미확정이면 채택하지 않는다.

기여 분리는 정책 변경 효과를 각 세계에서, 와이어 프로파일 효과를 각 정책에서 비교한다. 두 요인이 함께 바뀐 끝점 비교도 별도로 제시하되 같은 세계 비교라고 부르지 않는다. 직접 정책 차이에서는 공통 참조가 상쇄된다. 새46 B 세계의 절대 최적 후회는 별도의 최적 참조 검증 없이 주장하지 않는다. 기존39 B 세계에서는 W1의 전체 참조와 과거 v31·v32 자료를 그대로 검증해 추가 대조할 수 있다.

MC는 전체 수집을 마친 뒤 관측된 모든 행동의 합집합을 고정하고 수행한다. 고정 표본131072, seed850001, 기존 oracle.py의 공통 난수·가족 오차 산식을 사용한다. 행동을 성능에 따라 제외하거나 표본을 유리한 지점에서 멈추지 않는다. 서로 다른 행동에서 수치상 영분산 때문에 경계를 정의할 수 없으면 미확정으로 남긴다. 이 판단은 J6에서 적용한 기준과 같다.

수집 전 사본·계획·실행기 해시를 저장하고 dry-run과 smoke로 관측 경계·seed 인덱스·CID와 무관한 세계 계약을 확인한다. 수집 후 원자료 해시, 행동 빈도, 전체 목록, seed 짝, 세계 프로파일과 관측 이력을 독립 검사한다. 이 문서는 개발 시뮬레이션 계획이며 실제 네트워크 측정이나 확증 계획이 아니다.

J7의 전체 Go 관문에는 선행 L1의 거울 구현 차이가 남아 있다. 그 차이를 J7의 상한 시험 통과로 덮지 않는다. Python 정책의 성능 평가와 별개로 전체 관문 PASS가 필요하다. L1 거울은 G1 범위에서 분리한 독립 후속 과제로 다루며, G1 전체 완료나 미채택 L2~L5의 채택을 뜻하지 않는다.
