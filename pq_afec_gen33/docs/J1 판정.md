후보와 비용만 바꾼 사본은 g3/v33/policy_snapshots/J1_v1과 J1_cost_only_v1에 남긴다. 상태 4는 후보 상태 7을 거부한다. 후보 꼬리 시험과 model-world 어댑터는 experiments/v33/candidate_tests로 보존했고 별도 프로세스에서 검사한다. 활성 L1 복구 후 258개·하위 490개가 통과했고 실행 전후 소스 해시가 같았다. 정확히 복구한 L1에 새 W1 표본을 추가하지 않는다.

준비 중 발생한 시험·보존 오류도 보존했다. 처음에는 model-world 원자와 일부 시험 기대값이 꼬리 항을 반영하지 못했고, float 경계 비교와 수집 fixture도 수정 후 통과했다. 새 묶음 생성 뒤 git clean을 요구한 보존 순서 오류는 생성물 SHA를 검증하고 해당 경로만 커밋하는 방식으로 고쳤다. 보호 경로 검사는 16:34 KST GUARD_OK였고 기존 볼트 6경고의 변경 주체는 미확인이다. 보호 파일을 직접 고치지 않았다.
