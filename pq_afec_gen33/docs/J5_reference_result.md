# J5 first flight GE 참조와 조건부 추정 결과

반복45의 비활성 참조 단계다. 활성 L1·상태4·Go와 동결 세계는 유지했다. J5는 partial이며 전체 W1과 실제 피드백에서의 공동 학습을 아직 검증하지 않았다.

## 역사 자료와 모형

[봉인 원자료 재분석 / 정책 모형] 원래 p18 저널의 전체 서버 바이트 중앙값5822 B를 사용해 n_need=5로 계산했다. 관측 재전송 대용은 `not ok or initial_datagrams >= 4`이며 직접 측정한 first flight 실패 레이블은 아니다.

| 행동 | 연결 수 | 관측 HCT(ms) | iid J(ms) | GE J(ms) | 관측 대용 비율 | GE 실패 확률 | 관측−GE(ms) |
|---|---:|---:|---:|---:|---:|---:|---:|
| (0, 0, 3) | 231 | 61.357238 | 50.364976 | 62.755332 | 0.047619048 | 0.063180828 | -1.398094 |
| (0, 0, 4) | 1368 | 60.975798 | 50.067587 | 58.464599 | 0.040935673 | 0.042992012 | 2.511199 |

(0,0,4)의 잔차2.511199 ms는 감사에 기록된 처리 시간 수준이다. (0,0,3)의 잔차는−1.398094 ms이므로 모든 행동에 공통 처리 상수를 적합했다고 해석하지 않는다. 독립 검증자의240조건과 GE 참조 비용 차이 최대는1.1368683772161603e-13, iid 회귀 차이는0이었다.

## 후속 비행 상태

[패킷 사슬 모형] p=0.15,L=3,k=2,gen-2 기본 선행 배치다. first flight 실패 뒤의 상태를 이어 기대 시도 횟수를 계산했다. HCT 예측값이 아니며 모든 비행 끝까지 송신한다는 가정이다.

같은 행동 반복의 무한합과 gen-2 절단 차이는 m=1에서 약1.76e-10이다. 비용식의 독립 반복 계수를 GE 전체 재전송 비용으로 간주하는 해석을 버렸다. 실제 ACK·PTO·원본 재전송과 HCT 결합은 J3/J4에서 이어야 한다.

## 합성 추정 진단

seed31~50, 연결당6비트,1350연결, 창64와 사전 강도16을 유지했다. 각 seed의 마지막450연결 추정 평균을 다시20개 seed에서 평균했다. complete는 전멸까지 모두 관측한다. success_only는 원본2개를 복구할 수 있는 비행에서만 회신하는 누락 진단이다. 실제 네트워크 회신률이나 성능이 아니다.

## 검증과 남은 일

새 단위67개, 기존351개·하위548개가 통과했다. 원자료120파일·162000행의324000추정과240요약을 별도 누적 계산으로 검산했다. 감사 원본4개는 gen33·scratch 경로만 바꿔 실행했고 원본·사본·출력 해시를 저장했다. 기존 정책·세계·W1 계약14파일은 모두 불변이다.

W1 B10 개선과 B1~B4 및 전체0.5 ms 비열등은 미실행이다. 비용 모형의 예측 개선을 행동이나 HCT 개선으로 대체하지 않는다. 다음 단계는 동결 세계에서 동일 후보의 iid·GE 결정을 비교하고, p·L 공동 우도와 누락 관측을 연결하기 전에 행동 변화와 관측 범위를 점검한다. m≤4는 유지하며 상태 직렬화나 Go 정책은 바꾸지 않았다.
