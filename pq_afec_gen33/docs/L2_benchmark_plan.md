# L2 개발 벤치 계획

2026-10-31 반복 17, 새 정책 성능 실행 전 고정한다. 전송 세계, W1의 20개 seed와 15개 하위 셀, 19개 동결 참조, 판정 문턱은 유지한다. 기본 행동 평가 표본 수는 원래 프로토콜의 131072이며 seed는 850001이다. 기존 L1의 사후 정밀화 값을 새 행동에 섞어 쓰지 않고, 비교에 필요한 전체 행동 합집합을 한 family로 새로 평가한다.

후보는 상태5의 목적지별 EPS 적응과 결정 당시 등급 경계를 함께 쓰는 L2다. none·c1·ideal 각각 전체 300실행을 수집한다. c1은 기존 D14의 수동 회신 모형이고 ideal은 특권적 진단이다. 이전 L1의 900실행과 v31·v32의 600실행은 원형 출처·입력·완료 기록을 다시 검증해 읽는다. 직접 전후 비교는 같은 모드의 L2에서 L1을 뺀 값이다.

등급 경계의 시점과 EPS 적응의 기여를 나누기 위해, L2의 모든 코드와 경계 snapshot을 유지하되 Beta 갱신 결과를 채택하지 않는 고정 EPS 사본을 별도로 둔다. none·c1의 전체 600실행을 같은 seed와 세계에서 수집한다. 이 사본은 진단용이며 결과를 보고 후보로 바꿔 채택하지 않는다. 고정 사본과 L1의 차이는 경계 시점, 적응 후보와 고정 사본의 차이는 EPS 갱신의 기여다. 사본의 단일 함수 차이와 원본 SHA를 기록한다.

채택에는 C1과 none 각각의 L1 대비 15셀 비열등을 확인한다. 문턱은 기존 0.5 ms/연결이며 셀 사이 상쇄를 허용하지 않는다. C1의 v31·v32 비교도 계속 보고한다. L2의 직접 대상인 none B1 결과와 B2 결과, L1에서 실패한 none B6를 빠짐없이 남긴다. 개선 주장은 seed 95% 구간과 공유 MC 경계를 분리해 보고하며, 기대 비용 감소 근거 없이 구현만으로 채택했다고 쓰지 않는다. 미확정은 통과가 아니다. B2 절대 목표 달성을 L2 단독의 새 요구로 만들지 않는다.

EPS 진단에는 초기값·최종값과 궤적, 모드별 갱신·거부 분모, 등급과 결정 RTT 경계, 실패 연결을 포함한다. C1 회신이 없다는 이유로 EPS 분모에서 제외하지 않는다. B6·B7·B8과 S 교체 셀의 EPS 증가가 라벨 잡음만을 식별했다고 해석하지 않는다. 참 손실·world_class는 분석 열로만 쓰고 온라인 입력에 추가하지 않는다.

전체 raw가 완료된 뒤 family를 고정하고 기대 비용을 계산한다. 중간 성능을 읽고 사전 강도·등급 여유·표본·seed를 바꾸지 않는다. 기존 자료와 실패한 시도는 보존한다. 이 계획은 개발 비교이며 확증이나 실제 회신 비용 측정이 아니다.
