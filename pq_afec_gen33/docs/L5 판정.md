# L5 판정과 활성 정책

2026-11-02 정정: 아래 "활성 정책을 직전 L1 상태4로 복구"는 당시 사실이다. 지금 활성 정책은 v3.3.1-dev(상태 11)이고, C1 회신이 확인되기 전 목적지는 v3.2-dev와 같은 이진 우도·결정을, 범주 우도는 c1 경로에서만 쓴다. v3 parity 상한도 1452 B로 내려서 아래의 1461 B 같은 parity 후보는 지금 v3 후보에 없다. 근거 `docs/v3.3.1 활성 정책 수정.md` 1·5절.

c12000에서 none은 L1 0.121485→L5 25.032549 ms, 차이+24.911063, 조정 구간[23.775437,26.046689]다. C1은 0.139315→25.032549, 차이+24.893233, 조정 구간[23.731675,26.054792]다. 두 셀 모두 0.5 ms 허용치를 넘는 악화다. B5의 none/C1 차이-3.261987/-2.256370와 B6의-20.917953/-14.552788 ms 감소가 이 실패를 상쇄하지 않는다.

사후 진단에서 full none·C1·ideal과 single none·C1 각각 26980/27000연결이 1461 B parity를 골라 1452 B decoder 한도를 넘었다. C1 관측 검열 26195회, 회신 없음 785회가 있으며 categorical 갱신은 26980회다. 세계 코드에서 잘린 parity는 복구되지 않고 credit만 계상된다. 총 악화 중 이 요인의 기여는 별도 대조 전까지 미확인이다. L5_c12000_diagnosis_v1.md와 JSON에 입력 SHA·140추적·189000행을 보존했고 J7 및 E11에 연결했다.

L5 상태 9 후보와 single 진단을 보존하고 활성 정책을 직전 L1 상태 4로 복구했다. 활성 padfec·padfec3의 Python 파일은 시작 전 커밋 91432c35c122dd83bc946b2d53e68c96bd6fa14b와 바이트 단위로 같다.

채택하지 않은 사유: primary noninferiority failed or inconclusive; historical new-method validation: blocked_missing_inputs.

원래 none·C1 30셀 판정은 {'pass': 28, 'fail': 2}다. 전체 210대조는 {'inconclusive': 7, 'pass': 191, 'fail': 12}다. 모드별 전후 평균과 seed95%·공유 MC·조정 구간을 L5_bench.md에 남겼다. 보정 상한 0 미만인 주 비교는 ['l5_none:B5', 'l5_none:B6', 'l5_none:B12_c6000', 'l5_c1:B5', 'l5_c1:B6', 'l5_c1:B12_c6000']다.

B5/B6 관문: {'c1:B5': 'pass', 'c1:B6': 'pass', 'none:B5': 'pass', 'none:B6': 'pass'}. 역사 관문: blocked_missing_inputs.

두 새 산출법에 필요한 N·tail·완료 패킷목록이 과거 p13 다섯 판본과 H c12000 저널에 없다. 기존 유효 모형의 앵커 6/6과 cert12000→11 재현을 새 방법의 검증으로 쓰지 않았다. cert3340의 불완전 first flight도 완료 응답으로 쓰지 않았다.

독립 검사 63602408건이 477.725초에 통과했다. 원자료 3000실행, 150그룹, 210대조를 확인했다. 고정 118행동에 원래 N131072·seed850001을 사용했다. 새 수집은 1500실행·2055000연결이며 기존 1500실행과 합쳤다.

모든 완료 응답을 반영하는 후보는 실제 수신한 world data index를 중복 제거한다. 이는 QUIC CRYPTO 구간의 재분할을 검증한 어댑터가 아니다. S에는 data만 들어가고 legacy A_pre=41(k-1), u=0이면 0을 credit에서 한 번 뺀다. 추가 margin은 0이며 J6의 성능을 보고 교체 채택한 진단이 아니다. 현재 연결의 완료 크기는 해당 연결의 결정 전에 소급해 넣지 않는다.

핵심 후보 329시험·하위 524개, 수집·관측 52시험, 분석 37시험·하위 47개와 판정 21시험이 통과했다. 합성 집계 55289검사·12오류 주입 거부, 응답 2340검사·15오류 거부, B5/B6 216264검사·11오류 거부, B9 초기화 61검사를 보존했다. 복구 시험의 실제 결과는 L5_revert_check_02.log와 JSON에 있으며 실행 전후 소스 SHA가 같다. 상태 4는 후보상태 9를 거부한다.

최초 실패와 검사기 정정도 보존했다. native hct 키, tuple Counter 비교, B6 fixture 식별자, B9 reset_each_connection 전달과 음성 대조 예외를 고쳤다. 전체 결과를 읽기 전에 기존 공통 개선 조건을 판정기 v3에 명시했다. 후보·세계·seed·표본·문턱은 바꾸지 않았다.

E11에 역사 입력·실제 응답 식별과 채택 재검토를 등록했다. 의존은 J7·T4이며 S0→J7와 S4→T4 경로는 L5/G1에 의존하지 않는다. L5 blocked는 G1 선행 의존을 해제하지 않는다. 다음 J7은 S0만 의존하므로 진행할 수 있다. 실제 wire·Go·C1 회신 비용은 미검증이다. 결과는 개발 세계 시뮬레이션이며 확증이나 전체 동시 95% 보장으로 표현하지 않는다.

복구 실행기 첫 시도는 Windows 경로의 역슬래시 해석 때문에 pytest를 시작하기 전에 실패했다. L5_revert_check_01의 로그와 JSON을 보존하고 경로를 repr로 직렬화한 v2로 재실행했다. L5_revert_check_02는 351시험·548하위검사 통과, 소스 불변이다. 이 수정은 후보나 시험 기준을 바꾸지 않는다.

118행동 중 MC 102개에는 각각 N131072를 사용했고, 나머지 16개는 동결 세계의 구조적 결과다. 선택 기준과의 기대 격차를 후회로 표기했으며, 정확한 참 최적값과의 격차를 증명한 수치가 아니다.
