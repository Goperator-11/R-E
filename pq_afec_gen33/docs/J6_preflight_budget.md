# J6 사전 ACK와 후보 경계

이 문서는 반복21에서 성능 실행 전에 정한 개발 계약이다. 기준 정책은 J1 후보를 제거한 L1 상태4다. J6는 상태8을 쓰며 미채택 후보 L2·L3·J1의 상태5·6·7과 구분한다. Go 구현과 실제 Initial 관측은 G1·T4에서 맞춘다.

## 바이트 산술

ACK 제외 응답 prefix를 Q라 할 때 물리 게이트는 `3*credit > Q+A_pre`다. 현재 Q는 `1280*(n_need-1)`이고 임의 정수 prefix를 받을 수 있게 한다. 후보 필요 신용은 `(Q+A_pre)//3+1+(margin+2)//3`이다. margin은 서버 바이트 단위의 후보 여유이며 물리 비용이나 실제 송신량에 더하지 않는다.

개발 기본 margin은30 B로 고정한다. margin0은 기여를 분리하는 진단 후보다. margin20·40은 정수 경계 시험에만 쓰며 성능을 보고 기본값을 고르지 않는다. S7910·n_need7·k2·W1280·A_pre41에서 최소 δ는7, 기본 margin의 δ는12다. 실제 A_pre28·41·54의 단위 시험으로 ±13 B를 확인한다. ACK 유실 전체를 이 여유로 보장하지 않는다.

공유 gen-2 함수의 기본 A_pre와 margin은0이며 기존 인자·결과·순서를 유지한다. v3 결정 경로만 예산을 명시한다. 원본 k는 고정한다. ML-KEM의 사전 ACK를 피하려고 k1을 만드는 후보는 추가하지 않는다. 감사 A8-06의 키 공유1216 B와 실측 W1280·1281·1406에서 k2라는 근거를 R3로 넘긴다. W1452는 원문에서도 추정이다.

## 관측과 다음 연결

새 선택 입력 `preflight`는 source, small_initial_sizes, first_large_seen, srv_bytes_scope 네 필드다. source는 실제 클라이언트 Initial 분류 결과인 client_initial 또는 사건 세계 도착의 대용인 world_arrival_proxy다. 첫1200 B 이상 응답 전에 실제 수신한 작은 Initial만 목록에 넣는다. 동일 연결의 목록을 먼저 합친다. 수신 못 한 서버 송신과 C1 피드백은 넣지 않는다. 세계의 ack 토큰은 실제 QUIC Initial 분류를 검증한 결과가 아니다.

first_large_seen이 참이고 양수 합을 관측했을 때만 A_pre 이력을 갱신한다. 빈 목록이나 관측 없음은 서버 지출0이라는 증거로 쓰지 않는다. 목적지 상태에는 최근64개의 `(k,u,bytes,source)` 관측을 저장한다. 추정은 같은 k와 정확히 같은 uplink 입력 u의 최근16개 합의 중앙값이며 첫 유효 관측부터 쓴다. 짝수 중앙값은 정수 바이트로 올림한다. 관측이 없으면 기존41*(k-1), u0이면0을 legacy_estimate로 표시한다. 이는 모형 가정이다. 행동·배치·ACK 유실 차이까지 식별하지 않는다.

srv_bytes_scope는 includes_observed_preflight다. 같은 수신 바이트 합에서 식별한 작은 Initial 합만 빼 S_response로 넣고, A_pre는 물리 게이트에 한 번 넣는다. 관측이 없는 이전 API 입력은 legacy_unclassified로 표시한다. S 창의 범위가 바뀌면 기존 창을 비워 ACK 포함 값과 제외 값을 섞지 않는다. J6 수집기는 모든 모드에서 관측을 제공한다. 사건·재전송에 따른 기존 S 표본 선택과 마지막 패킷 prefix 보정은 L5의 남은 범위다.

현재 연결의 관측은 그 연결의 비용·등급 우도를 계산한 뒤 저장해 다음 결정에만 사용한다. 후보 생성·비용·등급·캐시 키에는 같은 A_pre와 prefix를 쓴다. 잘못된 입력은 상태를 일부 갱신하지 않는다. 상태4부터7은 묵시적으로 변환하지 않고 거부한다.

## 검증과 채택

고정 W1 세계·seed·손실 일정·프로토콜은 바꾸지 않는다. J6 full은 none·c1·ideal을 수집하고 margin0은 none·c1 진단을 수집한다. 주 비교는 full의 none과 c1 각각 기존 L1에 대한15셀, 총30셀이다. 모든 셀의 보정한 상한이0.5 ms/연결 이하여야 하며 c1에서 적어도 한 셀은 보정한 상한이0보다 작아야 채택한다. B12 c6000을 별도로 보고한다. 다른 팔의 유리한 값으로 주 비교를 바꾸지 않는다.

기존 v31·v32·L1 원자료를 보존하고 새 수집기·worker·관측 어댑터를 동결한다. 전체 행동 합집합의 독립 기대값을 N131072, seed850001,8worker로 계산한다. 기존 구간을 새 행동으로 재사용하지 않는다. seed 단위95% 차이 구간과 기존 MC99% 오차 보정을 함께 쓰며 전체 동시95% 보장이라고 부르지 않는다. 미확정 또는 실패이면 후보와 근거를 보존하고 L1으로 복구한다.

정수 경계·부분 도착·gen-2 기본값·margin·캐시·상태·관측 시점·유효성·trace 무영향 시험을 통과한 뒤 전체 수집을 시작한다. 실제 개발 측정과 확증 측정은 이 CPU 세계 평가에 포함하지 않는다.
