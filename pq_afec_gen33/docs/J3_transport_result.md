# J3 재전송 전송 세계 진단

별도 recovery_world.py의37시험이 통과했다. 기존 모드360대조에서 모든 기존 반환 필드와 사건 trace가 동결 worldsim.py와 같았다. T6의 pure-lead 후속 XOR·m0 예외·ACK 구간 제외·비행별 credit·두 번째 PTO200→600 ms도 확인했다. p1은 PTO 상한에서 실패하며 손실 없는 종료를 만들지 않는다.

사전 계획의6문맥·3행동·20seed·100연결·5모드, 총180,000연결을 모두 완료했다. 90그룹·1,800 seed 요약·90개 대표 trace와 압축 원시 행을 독립 재집계했다. 소스 해시·credit 상한·첫 실패 공통 난수도 일치했다. 원본 T6과 같은 조건인 (0,3,1)·m0에서 동결 originals_first와 T6 all+connection의 원시 행이 모두 같았다.

이 결과는 세계 진단이다. 현재 와이어의 재패킷화·ACK 소유권을 검증한 실측이나 폐루프 W1이 아니다. k2·RTT50·u2·p0.15·(0,3,1)의 T6 unacked+flight에서 첫 실패는 136/2000건이며 조건부 HCT는 238.853683 ms다. 두 단계 참조의 267.938282 ms와 -29.084599 ms 차이가 남는다. 과거 저널에 가까웠다는 이유만으로 현재 모형이 맞는다고 볼 수 없다.

RTT200은 첫 ACK보다 PTO가 먼저 발생하는 미해결 체제다. u0에서는 동결 세계가 사전 ACK를 생략하는 근사가 있으므로 타이머 차이를 실제 QUIC의 결론으로 읽지 않는다. p0.02·(0,3,1)은 모드별 첫 실패1건뿐이다. 이 조건의 실패당 평균은 표본 부족을 함께 적고 기준에 맞출 목적으로 표본 수를 늘리지 않았다.

수정한 뒤 parity 회계는 이 입력 집합에서 HCT의 큰 차이를 만들지 않았다. T6의 후속 XOR와 원본 범위는 일부 입력에서 HCT를 바꿨다. 모드 사이 차이에는 패킷 수와 난수 소비 위치의 변화가 포함된다. 아래 표는 설정별 결과를 설명하며 정책 성능의 유의한 개선을 주장하지 않는다.
