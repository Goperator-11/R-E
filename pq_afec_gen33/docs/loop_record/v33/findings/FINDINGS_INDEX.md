# 감사 결과 색인

모든 항목의 원문은 같은 폴더의 `audit-*.md`(본문), `verify-*.md`(검증)에 있다.
검증 열: CONFIRMED·PARTLY·REFUTED·UNVERIFIABLE은 반박 검증자 판정이다. 검증자가 없던 갈래(A2·A3·A4·A5·A8)는 '미검증'이고, Claude가 직접 확인했거나 다른 갈래가 독립적으로 같은 결론을 낸 항목은 비고에 적었다.
PARTLY는 반드시 검증 파일의 `CORRECTED` 문장을 정본으로 쓴다. proposal이 doubtful·harmful인 항목은 제안을 그대로 구현하지 않는다.
A2r1-·A6r1-은 같은 갈래의 1차 실행 결과다(사용 한도로 다시 돌아 두 벌이 생김). 2차가 정본이고 1차는 보조 근거다.
