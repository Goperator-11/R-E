# O2 참조와 추정기 진단 결과

비활성 Python 참조의 결정 산술과 입력 검증을 완료했다. 활성 L1·상태 4·Go·독립 세계는 바꾸지 않았다. O2는 partial이다. 독립 세계의 숨긴 업링크 평가와 실제 관측 추정기 연결은 남았다.

감사와 검증자의 서로 다른 S를 보존한 20개 맥락을 재현했다. 기본 경주표의 모든 후보 비용이 기존 layout.evaluate 직접 계산과 일치했다. 경주표 배율별 계산은 별도 모듈을 써 기존 전역 함수와 학습 캐시를 바꾸지 않는다.

검증자 원본은 시나리오별 oracle도 비용 최솟값+0.01 ms 안에서 바이트로 고른다. 이 참조의 후회는 정확한 비용 최솟값을 뺀다. RTT200·2%에서 원본 1.197150611 ms와 참조 1.206354335 ms의 차이는 그 정의 차이다. c12000·8%의 감사 3.800406059 ms와 검증자 4.272993264 ms는 서로 다른 S·후보에서 나온다. 두 입력을 합치지 않았다.

아래 표는 진단용 선형 합성 입력이다. 각 행은 20seed,64연결이다. 수렴은 상대오차 10% 이내가 5연결 연속일 때의 마지막 연결이며, 수렴한 seed의 중앙값만 적었다. 무잡음 5대역은 모두 8번째 연결에 첫 추정,12번째에 수렴했다. 참 RTT와 업링크는 관측 생성과 평가에만 쓰고 추정기에 전달하지 않았다.

바이트가 일정하거나 적격 증거가 없으면 미확인으로 남았다. 무제한의 평평한 RTT도 양의 기울기가 없어 미확인이다. 참 2 Mbps 입력에 바이트와 함께 늘어나는 지연을 더하면 추정기는 1 Mbps를 내놓았다. 적격 플래그만으로 교란을 제거할 수 없으며, 합성 수렴을 실측 수렴으로 옮겨 쓰지 않는다.

검증: 새 59시험, 기존 351시험·548하위검사 통과. 추정기 최근 64개는 목적지별 관측을 먼저 자른 창이고, 네 적격 증거의 기본값은 false다. 음수·비유한 입력, 후보 중복·크기, 최악 비용과 최악 후회의 구분, 정확 동점, 전역 q·캐시 불변, 관측 부족·노후·교란을 검사했다. 감사 원본 3개 실행 출력과 재현 원자료, 생성 스크립트·소스 해시를 함께 보존했다.

다음 단계는 W1 seed31~50와 기존 일정, 동결 독립 세계를 사용한 사전 계획이다. 고정 점질량 참조부터 평가해 모형 후회의 세계 전이를 확인하고, 실패하면 활성 정책에 채택하지 않는다. 활성 학습층에 붙이는 후보에는 전체 W1 짝비교가 별도로 필요하다. 실제 네트워크 u·경주·경로별 검증은 X2·X3의 의존을 유지한다.
