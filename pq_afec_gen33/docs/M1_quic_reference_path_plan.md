# M1 실제 QUIC의 기준 경로 시험 계획

지연 없는 로컬 연결에서는 첫 원본에 대한 ACK 뒤에 클라이언트가 새 Initial을 보내 보류 기한보다 먼저 CH를 완성하는 경로가 있었다. 기존 실패와 무조건 첫 송신 credit 명제의 한계를 유지한다. 이번 시험은 M1 평가 계획에 이미 고정한 큰 인증서 조건, 업링크2 Mbps·RTT50 ms를 시험용 전달 큐에 적용한다. 결과를 보고 속도·지연·margin을 탐색하지 않는다.

클라이언트에서 서버로 나가는 실제 UDP 바이트에 정수 ns 직렬화 대기와25 ms 전파 지연을 적용한다. 서버에서 클라이언트로 나가는 datagram은 직렬화 제한 없이25 ms 전파 지연만 적용한다. 각 방향은 FIFO이며 WriteTo가 수락한 바이트의 사본을 큐에 보관한다. 소거는 기존 fecConn의 최초 원본0 또는1에만 적용하고 추가 Initial은 억제하지 않는다. parity는 기존 와이어 형식을 그대로 쓴다.

무손실·첫 원본 소거·마지막 원본 소거의 세 조건에서 실제 TLS 연결 완료, 최초 원본2개, 소거별 복원0·1·1개와 첫 CRYPTO 전 미사용 parity3·2·2개를 검사한다. 물리 수신량 이내의 스택·pending 회계도 검사한다. 송신 사건은 이미 분리 검증한 qlog 계측을 사용한다.

수신기의 D20 설정은 변경하지 않는다. 이 큐는 Go 시험 안에만 있고 실제 측정 실행기나 정책에는 연결하지 않는다. 호스트 스케줄러와 애플리케이션 큐의 동작이 있으므로 실제 네트워크의 정밀한 지터나 HCT 분포를 재현한다고 주장하지 않는다. 실행 시간은 성능 비교값으로 쓰지 않는다. 실패하면 당시 소스와 로그를 보존하고 원인을 확인한다.
