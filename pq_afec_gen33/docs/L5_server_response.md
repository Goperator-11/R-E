# L5 서버 응답 관측과 혼합

2026-10-31 KST, 반복23. 성능 실행 전 고정한 개발 후보 설계다. 활성 기준은 L1 상태4, 커밋91432c35다. J6 상태8 후보는 채택되지 않았다. L5 상태는9이며 이전 상태를 거부한다. 이 문서의 상수와 채택 기준을 W1 결과로 바꾸지 않는다.

## 관측 범위

완료된 연결에서 실제로 수신한 data 조각을 응답 index로 중복 제거한다. 같은 index의 크기가 다르면 거부한다. 목록은 도착 순서가 아닌 index 순서다. 완료 시점 뒤에 도착한 데이터그램, ACK와 Retry, 중복 data를 각각 따로 센다. 전체 수신 합은 원래 srv_bytes와 일치해야 한다. 완료 증거가 없으면 부분 목록을 S 학습에 넣지 않는다. y와 HCT 사건 여부로 완료 응답을 버리지 않는다.

세계 입력의 출처는 world_receive_index_proxy다. index는 동결 세계의 응답 조각 식별자이며 실제 QUIC 패킷 번호가 아니다. 서버 송신 목록, 실제 인증서 크기, 손실 목록, server_first_flight_sizes를 정책 입력으로 읽지 않는다. 이 참값들은 관측 어댑터 시험에서만 대조한다. 실제 QUIC의 재분할과 새 패킷 번호를 처리하는 어댑터는 G1/T4 범위다. C1 rxRetx는 업링크 개수이므로 사용하지 않는다.

ACK는 응답 목록에 포함하지 않는다. A_pre는 활성 L1의 제한 업링크41*(k-1) B, 무제한0 B를 예산 식에서 한 번 적용한다. J6의 관측 A_pre 중앙값과 margin30은 이 후보에 포함하지 않는다. 물리 prefix의 엄격한 경계와 같은 A_pre를 후보 생성에 전달하며 추가 여유는0이다. 이 선택은 정확한 목록을 가정한 물리 산술을 검사하기 위한 개발 기본값이고, 실제 ACK 송신량의 불확실성에 대한 보장이 아니다. J6 margin0의 성능을 채택 근거로 사용하지 않는다.

## 두 산출법

관측 보정 함수는 S_eff = S_obs - tail - (N_obs - base_bin)*c를 계산한다. S_obs는 ACK와 중복을 뺀 응답 바이트, N_obs는 같은 범위의 조각 수다. tail은 출처가 있는 명시 입력이어야 한다. 마지막 조각 크기를 감사 제안의 그룹별 유효 tail 상수로 자동 대체하지 않는다. 누락·범위 오류·음수 결과를 거부한다.

물리 함수는 packet_sizes[:-1]의 합을 prefix로 반환한다. 판정은3*credit-A_pre > prefix다. 임의 크기 조각에서도 prefix를1280배수로 반올림하지 않는다. n_need 표시는 floor(prefix/1280)+1인 진단이며 비용과 후보 산술은 정확한 prefix를 쓴다. 응답이 정확히 한 조각이면 prefix0이다.

기존 유효 모형의 여섯 앵커6/6와 cert12000의11은 별도로 재검산한다. 확인한 p13 집계5판본과 H c12000 저널에는 개별 N·tail·완료 응답 목록이 없다. 두 새 산출법의 과거 실측 재생은 자료 부족이다. 그 상태에서 여섯 앵커에 맞는 보정 상수를 선택하지 않는다. 물리 방식은 세계에서 검증할 임시 후보이며, 이 검증만으로 카드의 역사 자료 관문을 통과했다고 쓰지 않는다. 완전한 과거 입력이 확보되기 전에는 L5를 done이나 활성 채택으로 바꾸지 않는다.

## 변화와 혼합

응답 바이트의 차이가 서버 패킷 크기 절반 이상이면 별도 크기 성분으로 취급한다. 패킷 크기는 해당 완료 응답에서 가장 큰 조각이다. 두 표본의 비교 문턱은 두 최대 조각 중 작은 값의 절반이다. 이력에서 알려진 성분이면 혼합 표본으로 추가한다. 알려진 성분 어디에도 속하지 않는 새 크기가 오면 최근 예측 창을 비우고 그 표본부터 시작한다. 성분 목록은 남겨 다시 나타난 체인을 혼합으로 인식한다.

최근 관측 창은64개, 성분 목록은8개다. 오래 관측되지 않은 성분을 먼저 축출한다. 동률은 생성 순서로 푼다. 이 수치는 메모리와 평균화 범위를 정한 개발 기본값이다. 성분 기준점은 최초 관측으로 고정해 점진적 이동이 무한히 같은 성분으로 남지 않게 한다. 알려진 이전 체인으로 돌아가는 변화는 새 체인만큼 빠르게 초기화된다고 보장하지 않는다.

예측 분포는 최근 창의 각 정확한(prefix, 응답 바이트, 최대 조각) 조합의 빈도다. 성분 중심이나 S 중앙값으로 prefix를 대신하지 않는다. 정렬 순서는 prefix, 응답 바이트, 최대 조각이다. 각 조합에서 후보를 만들고 행동 합집합 전체를 E_S[E_p[J]]로 평가한다. 단일 성분이면 곱셈 순서를 기존 단일 경로와 같게 둔다. 캐시 키에는 prefix와 A_pre가 들어간다.

이번 응답은 이번 결정이 끝난 뒤에만 들어온다. 결정 당시 예측은 기존 혼합 분포를 사용한다. 완료된 이번 응답을 관측한 뒤 arrivals 없는 손실 우도는 그 응답의 조건부 비용 모형으로 계산한다. 관측된 응답 크기를 조건으로 삼는 것으로, 이번 행동이나 사전 예측을 고치지 않는다. 실패·불완전 응답은 기존 결정 전 분포의 우도를 사용한다. C1 데이터그램 우도, hazard, EPS, 재평가, 감시층 반응은 L1 규칙을 유지한다.

관측 입력이 없는 기존 호출은 legacy_unclassified 경로를 유지한다. 완료 목록을 한 번 받은 뒤 입력이 빠져도 legacy 총바이트를 깨끗한 이력에 섞지 않는다. 범위 전환은 기록하고 옛 S 창을 비운다. JSON 검증과 관측 갱신은 실패 시 기존 상태를 보존한다.

## 검증과 채택

먼저 실제 수신만 사용한 관측, 중복·재정렬·완료 경계, 두 산출법, 엄격 부등호, 변화·혼합, 후보 합집합, 조건부 우도, 상태9 왕복과 구버전 거부를 검사한다. 원문 패킷 예시 중 cert3340의[1280,1280,1280]은 미완료 첫 비행이므로 완전한 응답 fixture로 쓰지 않는다.

W1의 세계·seed31..50·N131072·validation seed850001을 유지한다. full은 none·c1·ideal, 진단은 완료 관측만 적용한 single 경로와 혼합을 켠 경로를 구분한다. 비교 기준은 활성 L1이며 none·c1 각각15셀, 총30셀의 보정 상한이0.5 ms/연결 이하여야 한다. B5는 각 seed에서 새 체인 관측2개 이내에 시작한 연속 두 근접 최적 결정을 요구한다. B6는 현재 체인을 미리 아는 oracle이 아닌 혼합 최선 고정 행동을 기준으로 보정 후회 상한0.5 ms/연결 이하를 개발 판정 기본값으로 둔다. 원래 카드의 '최선 고정 수준'을 수치화한 값이며 exact equality를 주장하지 않는다. 역사 자료 관문과 함께 충족해야 채택한다. 불확실한 MC 경계를0으로 채우지 않는다.

single 진단은 동일한 수신 관측·물리 산술을 쓰되 최근 깨끗한 관측16개의 응답 바이트 중앙값에 가장 가까운 실제 표본 하나를 사용하고, 변화 초기화와 혼합을 끈다. 동률은 최근 표본을 고른다. 이를 통해 관측·산술 변경과 변화·혼합 변경의 기여를 분리한다. 관측 보정식은 tail 적합 자료가 없으므로 성능 팔로 꾸며 넣지 않는다.

원문 연결은 A1-12, A2-11, A2r1-10, A4-01, A8-06이다. A4-01의 사건 연결 제외 제안은 L5 카드와 충돌하므로 적용하지 않는다. A8-06의 전부 k2 및 p13 물리 계수의 일부 문장은 J6 재검산의 단서를 따른다. 자연 k는 O4에 남긴다.
