# J1 둘째 비행 손실 꼬리

2026-11-02 정정: J1은 채택되지 않았다(`docs/J1 판정.md`). 지금 활성 정책 v3.3.1-dev(상태 11)에서 아래 "L1의 실제 갱신"에 해당하는 3등급 우도와 도착 datagram 우도는 C1 회신을 본 목적지(c1 경로)에서만 쓰고, C1 회신이 확인되기 전 목적지는 v3.2-dev와 같은 1비트 이진 우도·결정을 쓴다. 근거 `docs/v3.3.1 활성 정책 수정.md`.

v3의 first flight가 성공했지만 증폭 예산 때문에 둘째 왕복이 필요한 가지에 q2·T2를 더한다. 뒤 parity T가 하나 이상이면 later 원본과 XOR parity가 모두 사라질 IID 확률은 p²이고, T=0이면 p다. T2는 3·(RTT + τ(lead·parity_bytes(W,k)+W,u)) ms다. 첫 원본 앞에 보낸 바이트와 첫 원본 하나만 RTT 표본에 넣는다.

`p_one_rtt`, `p_two_rtt`, `p_fail`은 first flight의 기존 분할을 유지한다. 재시도 배수 M도 first flight 실패확률만 사용한다. 학습에 넘기는 세 등급은 (P1, P2·(1-q2), Pf+P2·q2)다. `e`는 비1-RTT 확률 P2+Pf이며 꼬리 때문에 다시 증가하지 않는다. 명목 2-RTT 행동에 대한 기존 1비트 `event_prob`도 마지막 등급 확률을 반환한다. L1의 실제 갱신은 3등급 또는 도착 datagram 우도를 사용한다.

`later=off`와 `later=g2`는 기존 비교용 비용식을 유지한다. J1의 q2 식은 qamp.go의 v3 later XOR 경로에 대한 것이다. gen-2 later RS 경로의 손실 모형을 이 변경으로 고쳤다고 주장하지 않는다. 기본 정책과 이번 W1 후보는 `later=v3`다.

우도가 바뀌므로 기존 사후분포와 잔차 창을 그대로 이어 쓰지 않는다. 상태 버전은 7이고 1~6을 거부한다. 버전 5와 6은 채택하지 않은 L2·L3 후보에 남겨 둔다. Go 반영은 G1에서 한다.

검증 정정값을 기준으로 삼는다. RTT50.7 ms·2 Mbps·p=0.15에서 준비 계산의 비용 증가는 (0,3,1)1.756336 ms와 (0,0,4)3.766348 ms다. 관측 초과 꼬리 1.672236 ms와 4.289507 ms의 차이를 그대로 보고한다. 교차점은 표본 RTT 식에서 0.2147906이며 참 RTT만 쓰는 식의 0.2173651과 구분한다. 이 값을 맞추려고 PTO나 q2를 조정하지 않는다.

GE 검산은 first flight 패턴 질량을 재가중한 뒤 세 등급의 합이 1인지 확인하는 대수 검사다. 연속 두 패킷 손실의 조건부 확률은 IID p²와 다르므로 GE 물리 정확성 검증은 J5에 남긴다. J2의 처리 시간과 J3의 first flight 실패 타이머도 이번 변경에 넣지 않는다.

개발 평가 전에 후보를 동결한다. W1의 15시나리오·seed31~50·기존 세계와 공통 난수를 그대로 사용한다. 채택 후보는 비용과 등급을 함께 바꾼 판이며 비용만 바꾼 판은 기여 분리용 진단이다. none·c1 각각 L1 대비 15셀의 조정 95% 차이 상한이 0.5 ms/연결 이하이어야 한다. 적어도 한 주 비교 c1 셀에서 차이 상한이 0 미만이어야 한다. ideal과 v31·v32 대조, B1·B2 절대후회, 모든 미확정 판정도 함께 공개한다. 새 선택 행동을 포함한 전체 행동 집합에 N131072·seed850001을 한 번 적용한다. 결과가 실패하거나 미확정이면 후보를 보존하고 L1으로 복구한다. 결과를 보고 진단 판으로 대체하거나 표본을 추가하지 않는다.

고정 팔의 A0 관측 평균·꼬리 초과분, 수정 전후 모형값, W0 세계값과 구간을 별도 열에 놓는다. 봉인 자료를 읽어 개발 모형을 점검하는 작업이며 봉인 판정이나 확증 결과는 바꾸지 않는다.

`experiments/adaptation_benchmark.py`는 정책 비용식의 원자를 표본화하는 model-world 진단이다. 둘째 비행의 정상·꼬리 원자를 확률 1-q2와q2로 분리해 수정된 비용식의 기댓값을 재현한다. 독립 W0 전송 세계와 W1 채택 평가 소스는 변경하지 않는다.
