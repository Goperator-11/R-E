# J5 버스트 참조 구현과 관측 계약

2026-11-01 반복45의 성능 계산 전에 고정한다. 이번 단계는 비활성 Python 참조다. 활성 L1, 상태 판본4, Go 정책, W0 세계와 W1 일정은 유지한다.

## L의 의미

물리적 평균 연속 손실 길이를 L이라 하면 G→B 확률은 p/[L(1-p)], B→G 확률은 1/L이다. 따라서 iid 경계는 L=1/(1-p)다. L=1은 연속 손실이 없는 사슬이며 iid가 아니다. W0는 이 물리적 정의를 그대로 사용한다.

정책 참조의 `mean_burst`는 gen-2 `GilbertElliott.for_prior`의 의미를 따른다. 입력이 iid 경계 이하이면 버스트 증거가 없는 것으로 보고 iid를 사용한다. 그 위이면 실제 평균 길이로 사용한다. 이렇게 `mean_burst=1` 회귀 요구를 만족하면서 p18의 L=3 의미도 보존한다. 유효 L과 입력 L을 구분해 기록한다. p=0과 p=1은 각각 무손실·전손실 경계이며 유한 평균 길이 추정 대상이 아니다. 잘못된 확률, NaN, 무한대, bool과 L<1은 거부한다.

## first flight와 후속 비행

송신 순서의 각 도착 비트에 대해 두 상태 forward 재귀를 계산한다. 참조는 기존 layout의 순서·복구 판정·시각·credit·경주 분기를 그대로 사용하고 확률만 바꾼다. iid는 기존 곱셈 순서를 유지하며 모든 반환 수치의 오차가1e-12 이하여야 한다. first flight GE 비용은 감사의 재현용이다. 기존 `M=1/(1-p_fail)`을 그대로 쓴 비용을 GE 재전송 전체의 정확한 HCT라고 부르지 않는다.

별도로 first flight 실패와 다음 송신 상태의2×2 행렬 F를 만든다. 명시된 후속 행동의 실패 행렬 R에 대해 E=1+πF(I-R)^(-1)1을 계산한다. 이는 모든 비행을 끝까지 보내고, 패킷마다 상태가 전이하며, 대기 중 전이하지 않는 모형의 기대 시도 횟수다. first flight와 후속 비행 행동을 다르게 지정할 수 있다. 실제 ACK·PTO·중간 성공 시점·서버 응답이 섞인 HCT와 구분한다. A4-08의 상태 이월 요구를 이 계산으로 점검하되 J3/J4를 대체하지 않는다.

## 도착 비트맵 추정

목적지별 최근64개 연결을 먼저 고르고, 그 안의 완전 송신·물리 도착 증거가 있는 C1 또는 ACK 비트맵만 사용한다. 회신 없음, 잘림, 비트맵 없음은 추정에서 제외한다. 복원한 원본을 물리 도착으로 넣지 않는다. 전멸도 명시적으로 확인된 완전 증거이면 포함한다. 빈 관측도 창을 차지하므로 오래된 증거가 영구히 남지 않는다.

연결 안의 인접 두 비트만 세어 B→G와 B→B 횟수를 구한다. 연결 끝을 성공으로 채우거나 다음 연결의 첫 비트와 잇지 않는다. p는 호출자가 제공한 현재 손실률이다. B→G 확률 b의 사전분포를 Beta(16(1-p),16p)로 두고, 관측 뒤 평균을 (BG+16(1-p))/(BG+BB+16)으로 계산한다. 모형에서 b는1-p 이하로 제한해 음의 상관을 채택하지 않는다. 이 사후 평균의 역수로 유효 L을 구한다. 사전 강도16·창64는 결과에 맞춰 바꾸지 않는다.

이는 p가 주어진 조건부 추정 진단이다. 독립 손실 우도로 계산한 기존 p 사후분포를 GE의 정확한 공동 사후로 간주하지 않는다. 실제 피드백의 선택 편향, 누락과 p·L 동시 추정은 활성 연결 전에 별도 관문으로 남긴다. 아직 상태 저장 형식을 추가하지 않는다.
