# 코드 지도

gen33 작업 트리에서 활성 정책 v3.3.1-dev가 도는 경로와, 미채택하거나 보류한 후보의 보존물, 관문, 세계 시뮬레이션 도구를 파일 단위로 가른다. 파일은 옮기거나 지우지 않았다. 함수 이름만 적고 행 번호는 적지 않는다. 지금 행 번호는 `python -I -B tools/check_algorithm_map.py`가 7절 표의 이름마다 출력한다. 이 문서의 검사는 `tests/test_code_map.py`, 후보별 파일 목록은 [후보 색인](../g3/v33/CANDIDATE_ARCHIVE.json)과 `tests/test_candidate_archive.py`가 맡는다(F52, F43).

## 1. 활성 정책

결정은 Python `padfec3`와 Go `experiments/quicbed/policy3.go`가 같은 산술로 내린다. C1 회신을 아직 보지 않은 목적지(`c1_seen=False`, none 경로)는 parity 상한을 맞춘 v3.2-dev와 같은 1비트 이진 우도와 결정을 쓴다. C1 회신을 본 목적지(c1 경로)만 datagram arrivals 우도와 HCT 3등급 우도를 쓴다. 상태 판본은 11이다. 명세는 [SPEC](PAD-FEC%20v3.3.1%20명세.md)와 [활성 정책 기록](v3.3.1%20활성%20정책%20수정.md)에 있다.

| 파일 | 담는 것 |
|---|---|
| `padfec3/learn3.py` | 목적지 상태 `DestState3`, 사전과 hazard 예측, 1비트 우도와 arrivals 우도, 3등급 라벨, guard, S와 k 추정. CX1 원장 필드 `x_ledger`는 기본 None이고 그때 상태 JSON에 나타나지 않는다. |
| `padfec3/decide3.py` | 후보 생성 `candidates3`(1452 B 상한 포함), J_TIE 동률 규칙, `decide3`. `explore` 인자는 기본 None이다(CX1 보류). |
| `padfec3/layout.py` | v3 첫 묶음 [L,O,T]의 도착 결과, A_pre, 1-RTT 조건, 실패 가지를 포함한 비용 `j3`. |
| `padfec3/__init__.py` | 패키지 표지. |
| `padfec/policy.py` | padfec3가 import하는 공유 상수와 함수(`T_PTO_NO_ACK_MS`, `J_TIE_MS`, `QUICGO_MAX_IPS`, `parity_datagram_bytes`, `race_win_prob`). gen-2 정책 `decide_v2`도 이 파일에 있다. |
| `padfec/quantum.py` | 서버 packet 크기 `P_SERVER`, 증폭 배수 `AMP`, `bin_index`, `bin_needed`. |
| `padfec/table.py` | 손실률 격자 `P_VALS`(learn3의 G)와 Go 표 `experiments/quicbed/pfail_table.go` 생성. |
| `padfec/amplif.py`, `padfec/capacity.py` | `padfec/policy.py`와 `padfec/quantum.py`가 import한다. |
| `padfec/codec.py` | Python 부호기. GF(256) RS `RSErasureCode`는 [afec/rs.py](../afec/rs.py)에 있다. 테스트베드 형식과의 차이는 7절 codec 행에 있다. |
| `experiments/quicbed/policy3.go` | auto3 정책의 Go 구현. 후보 생성, 동률, 관측, 상태 캐시, CX1의 `p3ExploreStep`(rate 0이면 바로 돌아간다). |
| `experiments/quicbed/policy3_l1.go` | arrivals 우도와 3등급 함수(c1 경로에서 쓰는 활성 코드)와 참조 실행기 `p3RunL1Reference`. 이름은 역사적이다. |
| `experiments/quicbed/pfail_table.go` | `padfec/table.py`가 만든 표와 공유 상수 `quicgoMaxIPS`, `jTieMs`. |

`padfec/`와 `padfec3/`의 어느 파일도 `experiments.v33`나 `g3.v33`를 import하지 않는다. `tests/test_candidate_archive.py`가 두 패키지 전체를 ast로 읽어 이것을 고정한다.

## 7. 수량별 알고리즘 지도

이름은 백틱 안의 파일에 실제로 있어야 하고 `tools/check_algorithm_map.py`가 ast(Python)와 정규식(Go)으로 찾는다. 미채택 항목은 [미채택 후보 기록](미채택%20후보%20평가%20기록.md)을 가리킨다.

| 수량 | Python 함수 | Go 함수 | 시험 이름 | 비고 |
