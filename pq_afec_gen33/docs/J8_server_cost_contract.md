# J8 프로필별 복구 비용 계약

`recovery_reference.evaluate`의 새 선택 입력 `server`는 ServerCost다. 서버 프로필과 실제 datagram 크기 목록을 받으며 n_need와 목록 길이가 다르면 거부한다. 기존 호출은 기존 J3 두 단계 참조를 그대로 쓴다. 활성 학습 정책에는 연결하지 않는다.

명시적 서버 프로필이 있으면 초기 PTO는 그 프로필 값을 쓴다. 기존 표본 PTO 배수와 ACK 식은 그대로 둔다. 성공·첫 재전송·강제 종료의 모든 완료 가지에 같은 서버 예산·IW·선행 credit·뒤 경주를 적용한다. 재전송의 물리적 선행 바이트와 시간은 lead_credited가 false여도 남고, 스택 credit만 빠진다. 이전 비행과 현재 비행의 심벌은 합치지 않는다.

하향 무손실 완료 시각은 첫 서버 datagram이 키 수립과 손실 없는 클라이언트 응답을 가능하게 한다는 근사다. 첫 묶음은 실제 크기와 이전 ACK 지출에 따라 제한한다. 클라이언트 응답 뒤 주소 검증이 끝나고, 남은 datagram은 고정 IW개씩 보낸다. 첫 추가 왕복에는 W B 응답, 이후 각 왕복에는 명시한 ACK 크기의 직렬화를 청구한다. 이는 동결 W0의 고정 패킷 창과 비교할 참조이며 실제 혼잡 창 증가나 UDP 묶음 분할 모형은 아니다.

하향 손실 p_d가 양수면 현재 단계는 J=None, cost_complete=false를 반환한다. 손실 없는 반사실 계산값과 손실 확률은 별도 필드로 보존한다. 이는 하향 재전송 시간·주소 검증 시각이 아직 해결되지 않았다는 표시다. 이 값을 행동 선택 점수로 사용하지 않는다. 예산만 맞는 재전송을 시간 비용까지 맞는 것으로 취급하지 않는다.

검증 계획은 기존 무프로필 결과의 원본 함수 대조, 같은200.86 ms 입력에서의 이전 참조 회귀, 명시적200·999 ms PTO의 닫힌형, exact·granular의1 B 경계, 짧은 마지막 datagram, IW 다중 왕복, credit 미지원, 잠정 하향 손실 거부다. 무손실 W0 비교는 p=0, p_d=0, 처리 지연0, 경주 지연0, 추가 타이머 비활성 조건으로 한정한다. 그 조건의 일치와 실패 비용·전체 HCT의 실측 적합성을 구분한다.

행동 표는 실제 후보별 k가 고정이라는 가정 아래 m≤4·parity1452 B 상한을 적용한다. 프로필별 최소 credit 경계와0·1 B·상한을 후보로 만든다. 현재 크기·손실확률·경로를 아는 고정 입력의 비용 비교이고 목적지 학습·전체 W1 결과가 아니다. p_d가 양수면 선택을 거부한다. 실제 k 변화·dup·pad 공통 비용은 E27·E32의 후속 범위다.
