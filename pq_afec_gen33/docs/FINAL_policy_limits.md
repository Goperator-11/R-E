# 활성 정책의 알려진 한계

2026-11-07, F44. 활성 정책은 v3.3.1-dev, 코드 위치 기준은 359612d9e다. 이 문서는 정책 산술을 고치지 않고 남은 한계와 적용 조건을 기록한다. C1 이력이 없는 none 경로는 v3.2-dev와의 재생 동치를 유지하고, c1 경로는 L1 관측과 L3 record_only 결정을 쓴다. C1은 표준 QUIC에 없는 비인증 서버 회신이다.

각 행은 세계 시뮬레이션, 비용 모형, 과거 봉인·개발 측정, 코드 확인을 구분한다. 개발 시뮬레이션 수치는 실측이 아니다. 개발 측정은 confirmatory가 아니다. 한계를 기록한 사실이 개선을 확인한 결과는 아니다. 이번 F44는 새 후보·측정·재생을 실행하지 않았다. [주장 기준](REPORT_CLAIMS_v33.md)과 [미채택 후보 기록](FINAL_rejected_candidates.md)을 함께 따른다. 제출 보고서 원본은 수정하지 않았으며, 표의 반영 열은 저장소 문서 반영 상태다.
