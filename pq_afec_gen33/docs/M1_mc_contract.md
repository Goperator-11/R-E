# M1의 세계 간 MC 오차

평가 계획은 기대 비용을 주 결과로 두고 수신기 변경의 끝점 비교를 포함한다. 이때 서로 다른 세계의 공통 참조 비용은 상쇄되지 않는다. 기존 J7의 세계 간 표는 점추정만 보고했으므로 그 표를 그대로 합격 판정에 쓰지 않는다. 아직 M1 MC 자료를 생성하거나 열람하지 않은 단계에서 아래 산식을 고정한다.

모든 정책·관측 모드의 행동과 과거 v31·v32의 행동을 합친 가족의 크기를 F라고 한다. 각 행동의 독립 표본은 계획대로 131072개, seed 850001이다. 같은 문맥·seed·연결 번호의 환경 난수를 각 행동과 세계에서 재사용한다. 원래 W0의 구조적 무손실 증명은 새 세계의 소스에 적용하지 않는다.

같은 세계의 정책 비교는 기존 W1처럼 행동별 공통 참조와의 차이를 사용한다. 세계가 다르면 행동별 절대 HCT 평균을 사용한다. 두 통계량 가족을 함께 다루므로 전체 99% MC 가족에 정규근사의 양측 보정값 `z = Phi^-1(1 - 0.01/(4F))`를 쓴다. 즉 F개의 차이와 F개의 절대 평균을 합친 2F개 값에 오차 예산을 배분한다. 기존 차이 표의 보정값보다 작게 만들지 않는다. 정규근사는 분포와 무관한 보장으로 표현하지 않는다.

같은 세계의 폭은 `z * sqrt(gap_variance / n)`, 서로 다른 세계의 각 항 폭은 `z * sqrt(variance_hct / n)`이다. 모든 seed에서 평균한 행동 가중치 차이의 절댓값에 각 폭을 곱해 합한다. 세계 간에는 같은 행동 이름이어도 다른 문맥 ID로 남기므로 두 항을 임의로 상쇄하지 않는다. 그 합을 seed 차이의 95% 구간에 더하고 뺀다. 교차 세계의 공분산을 추정했다고 주장하지 않는다.

직접 차이의 영분산은 기존 기준대로 서로 다른 행동이면 미확정이다. 절대 평균의 수치상 영분산도 새 구조적 증명이 없으면 미확정이다. 항의 계수가 정확히 0이면 해당 항의 폭은 필요하지 않다. 자료가 부족하거나 불확실성이 정의되지 않으면 비열등을 통과시키지 않는다. 0.5 ms 문턱과 C1 감소 조건은 바꾸지 않는다.

역사 자료의 trace는 원래 W1 해시·수집 목록·관측 기록으로 다시 검사한다. 원래 문맥 ID는 보존하고 off 세계의 동일 문맥으로 옮긴 행동 빈도 사본을 따로 만든다. 새 세계는 보류를 끈 경로의 결과가 기존 W0와 같은지 먼저 시험했다. 원자료를 고치거나 다른 세계의 자료라고 다시 이름 붙이지 않는다.

고정 행동 검산은 별도 `m1_fixed_world_report.py`가 같은 MC 가족의 16행동을 읽는다. 큰 인증서·지터 없음·2 Mbps·RTT50의 p=0.02와0.15에서 두 세계의 각 행동 기대 HCT와 차이를 보고한다. model-world J와 first flight 실패 확률은 원래 검산 JSON에 남기고 독립 세계 HCT로 바꿔 부르지 않는다.

16개 행동 중 최소 비용의 구간은 행동별 하한의 최솟값과 상한의 최솟값이다. 두 세계의 최소 비용 차이는 각 세계의 이 구간을 보수적으로 빼서 구한다. 결과를 보고 고른 행동 하나의 구간으로 최솟값을 대신하지 않는다. 이는 사전에 정한 유한 행동 목록의 최소값이며 전역 최적값이 아니다. 2% 손실의 행동별 차이를 명목 기한 상한과 함께 보여 주되 새 채택 기준을 만들지 않는다. 주 120셀 판정과 C1 감소 조건은 원래 계획을 유지한다.
