# S4 이식 결과

R-E의 73aa420 수정 9파일을 gen33에 옮겼다. qamp.go의 v3와 M1 경로를 유지하며 parity만 받는 경로의 만료, heldBytes 해제, 상충 metadata 거부를 추가했다. 실제 copy 길이 계상은 M1에서 이미 고친 동작을 유지한다. v3의 ver·lead 충돌도 두 수신 경로에서 검사했다.

gen33 내부 gen-2 결정에는 의도된 변화가 있다. RTT는 새 ACK 표본의 EWMA를 쓰며, 오래된 C1은 연결·결정 나이에 따라 제외한다. 보호 콜드스타트 뒤 손실 관측이 없으면 초기 무보호 관측을 하되 명시적으로 탐색을 끈 경우는 존중한다. 심벌 손실의 미확인 순서는 평균 감쇠로 처리한다. afec 사전은 for_prior이고 expected_rounds는 512항목 LRU다. Python 회귀 6시험·하위 89개는 통과했다.

D21에 따라 gen-2 목적지 캐시를 명시판본 1로 저장한다. 이전 map은 기존 통계를 보존하고 새 RTT·C1 출처 계수를 0으로 변환한다. 판본 왕복·이전 상태 변환·잘못된 14형식의 전체 거부를 검사했다. JSON 중복 키와 모든 수치 범위를 새로 검사한 것은 아니다. 파일 쓰기 오류를 반환하지 않는 기존 API 한계도 남는다.

수정 전 회귀는 Python 보고 10실패·2통과·하위 2통과와 Go 상위 3시험 실패였다. 잘린 pending 복원본 시험은 M1 수정 덕분에 이식 전부터 통과했다. 수정 뒤 Go145시험, vet·race, 핵심 Python351시험·하위 548개를 통과했다. M1 실제 ReadFrom700116사례도 통과했다. 전체 로그와 소스 불변 영수증은 runs/S4_*에 보존했다.

v3 참조는 원본 2800기초값·6720결정·50000궤적 단계와 fresh2600기초값·5000결정·40000궤적 단계의 5절 관문을 통과했다. E12 참조와 계산 내용은 같으며 timing_s와 padfec/policy.py 소스 지문만 달라졌다. S4_reference_equivalence_v1.json의 trajectory_steps:null은 작성 스크립트가 a 대신 action 키를 찾은 기록상의 한계다. 원본 기록을 덮지 않고 S4_result_v1.json에서 실제 a 길이 합 50000을 검산했다. 기본 참조 파일은 이번 관문에서 통과한 파일과 같은 바이트로 갱신했다.

W1은 기존 L1의 45그룹·900실행·1233000연결을 같은seed31~50으로 재실행했다. 전체 압축 trace 바이트, 행동 계수, 최종 상태, 요약이 같다. 실행 영수증·소스 import 지문을 검증하고 요약을 원자료에서 다시 계산했다. HCT 차이는 모든 그룹 0ms다. S4_bench.md의 고정 짝차이 95%구간[0,0]은 이 표본의 동치이며 일반 성능 향상 주장이 아니다. 같은 문맥·행동의 기존 MC 비용 항목도 같으므로 새 MC 추정은 필요 없다.

공유 파일 점검은 다섯 로컬 세대의 afec·padfec Python과 qamp.go·policy.go85파일을 읽는다. g3/v33/shared_drift_v1.json에 네 경로의 알려진 세대 차이와 이유를 선언했다. tools/drift_check.py는 CRLF만 LF로 정규화하며 선언하지 않은 내용·추가·누락 파일을 실패로 보고한다. 현재 0건이고, CRLF 허용·내용 변경·파일 추가·누락의 4개 보존형 fixture를 검사했다. 이 도구는 지문을 자동 갱신하지 않으며 세대 간 의미 동치를 증명하지 않는다.

D5의 비교 gen-2는 동결d98b05d7 그대로다. 수정된 gen33 서버와 동결 서버를 각 팔에서 쓰면 decoder 차이가 교란이 된다. T7은 기존 카드의 A6-M03 경고와 함께 같은 서버 대조 가능성을 계획에 적고, R2는 초안에 서버 선택·분해 비교를 명시해야 한다. policy3 최소 RTT 문제는 O3에 남는다. 이식으로 봉인 결과나 미채택 후보의 상태를 바꾸지 않았다.

초기 이식 스크립트는 import sys가 하나라는 가정 때문에 중간에 중단됐다. 수정 전 6파일은 이미 보존되어 있었고 후속 LRU 두 줄을 명시 적용했다. 실패 스크립트·설명과 최종 9파일 지문을 남겼다. 결과를 보고 seed·기준·정책을 바꾸지 않았다.
