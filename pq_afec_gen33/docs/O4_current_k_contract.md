# O4 현재 연결 k의 정책 후보 계약

이 후보는 활성 L1을 바꾸지 않는 Python 어댑터다. D35의 완성된 FirstHello로 현재 k를 계산하고 결정과 그 연결의 관측 분류에 같은 k를 쓴다. S·RTT·손실 사후·감시 계수·기존 행동 후보는 유지한다. k만 바꾸고 관측 분류에서 과거 k를 다시 쓰는 경로를 허용하지 않는다.

활성 함수의 산술을 재사용하려고 연결별 임시 상태 사본의 k 문맥만 현재 값으로 바꾼다. 실제 상태에 저장하는 k_hist는 과거의 실측 이력을 그대로 보존하고, 성공 관측에서 받은 유효 k_obs만 기존 규칙으로 추가한다. 임시 문맥 값을 관측 이력으로 저장하지 않는다. 스키마가 바뀌지 않으므로 상태 판본4를 유지한다. 후보 식별자는 별도 필드로 표시한다.

decide는 한 연결을 시작하고 observe가 끝나기 전 다음 decide를 거부한다. 오류에서는 상태를 원자적으로 보존한다. 진행 중인 연결은 직렬화하지 않는다. 현재 k를 계산할 수 있어도 S가 없으면 기존 cold 행동, RTT가 없으면 no_rtt 행동이다. 이때도 첫 비행 expected_k는 계산할 수 있다. 계산 결과가 정책 범위 k1~4를 넘으면 기존 k_range 행동을 유지한다.

기존 후보 집합의 모든 W_eff에서 natural_k가 결정 때의 k와 같아야 한다. 다른 k가 필요한 후보를 발견하면 UnsupportedRepacking으로 전체 결정을 거부하고 상태를 바꾸지 않는다. 일부 후보를 숨겨 선택하거나 k_floor를 강제하지 않는다. 이 후보는 k가 유지되는 범위에 한정하며, 변화 경계의 정책은 별도 구현·세계 검증을 요구한다. 명시 action에도 같은 조건을 적용한다.

관측 때는 해당 연결의 action·W·u·c_pkt·현재 k를 사용한다. k_obs가 양수인데 예상 k와 다르면 묶음 분할이나 입력 불일치이므로 거부한다. k_obs0은 미확인이며 실제 k 이력에 넣지 않는다. C1 물리 도착 증거와 HCT 등급의 기존 우도 선택은 바꾸지 않는다. 명시 expect-k와의 실제 우선순위, 취소·Retry 처리와 전송 종료는 Go 연결 단계에서 검증한다.

검사는 현재 k와 과거 최빈값이 다른 상태, 이력 없는 상태, 실패·C1·none 관측, 재진입·중복 관측·입력 오류의 원자성, k 변화 후보 거부, 기존 k와 같은 문맥의 정확한 결과·상태 동치를 포함한다. 활성 채택 전에 W1의 같은 seed31~50·B1/B2 일정과 전체 비열등 기준을 적용한다. 결과를 보고 문턱·seed·사전이나 k 범위를 고치지 않는다.
