# O3 RTT 참조 계약

2026-11-01 반복47에서 성능 실행 전에 고정한다. 이번 단계는 Python 참조와 관측 계약이다. 활성 L1 상태4, Go, 세계의 시간 생성과 W1 기준은 유지한다.

정책 RTT는 적격 연결 표본의 EWMA로 계산한다. gen-2 `policy.go`의 순서대로 첫 표본은 그대로 쓰고, 이후 `old * 0.75 + sample * 0.25`를 쓴다. 최소 RTT는 별도로 보관한다. 변동은 갱신 전 EWMA와 표본의 절대 차이를 `old_var * 0.75 + abs(old_mean - sample) * 0.25`로 반영하고, 첫 표본에서는 `sample / 2`로 시작한다. 이는 연결 간 변동이며 quic-go의 연결 안 RTTVAR와 같다고 주장하지 않는다.

보정 입력은 ACK와 송신 패킷이 명시적으로 연결된 원시 RTT, 그 패킷 앞의 대기 바이트, 그 패킷의 데이터그램 바이트, shim 대기 시간, 알려진 업링크와 이미 적용할 수 있는 ACK 지연이다. 표본에서 `0.008 * (queued_bytes + datagram_bytes) / uplink_mbps`, shim 대기, 명시 ACK 지연을 뺀다. 업링크0은 무제한, None은 미확인이다. 미확인 속도에서는 직렬화를 0으로 만들지 않는다. 이미 ACK 지연이 보정된 LatestRTT에 같은 지연을 다시 빼지 않도록 원시 표본만 받는다.

고정 quic-go는 Initial ACK의 delay 필드를 적용하지 않는다. Initial 표본의 명시 ACK 지연은0이어야 하며, 나중1-RTT 표본도 transport에서 적용 가능한 지연만 받는다. 원시 ACK의 delay 필드를 그대로 빼는 구현은 허용하지 않는다.

이 바이트는 해당 패킷이 기다린 실제 대기량이다. 연결 전체 첫 비행 바이트나 선택 행동만으로 채우지 않는다. MinRTT의 소유 패킷을 모르면 보정 입력으로 쓰지 않는다. ACK 검증, 패킷 귀속, 대기량의 근거가 없는 입력은 이유를 반환하고 추정에 넣지 않는다. 처리 지연과 하향 직렬화는 관측 계약에 없으므로 보정된 ACK RTT에 남을 수 있다. 결과를 순수 전파 RTT라고 부르지 않는다.

한 연결에서 대기 바이트와 shim 대기가 모두0인 나중 1-RTT ACK 표본이 있으면 가장 나중 것을 고른다. 없으면 귀속을 확인한 Initial ACK의 가장 나중 표본을 쓴다. 최소 표본을 고르는 선택 편향을 추가하지 않는다. 나중 표본이 없는 연결에 표본을 만들어 넣지 않는다. 연결 번호는 증가해야 하고, 표본 부재도 연결 번호를 전진시키되 EWMA·최솟값·변동을 갱신하지 않는다. 같은 연결의 표본을 두 번 학습할 수 없다.

등급 경계는 기존 L1의 첫째·둘째 경계에 각각 `4 * rttvar_ms`를 더한다. 사건과 감시 문턱은 `max(0.5 * rtt_ms, 4 * rttvar_ms)`다. 경계의 비교 방향은 기존 분류기와 같게 유지한다. 최초 변동의 큰 여유와 경로 급변 직후의 탐지 지연도 결과에 포함한다. 상수4를 지터 결과에 맞춰 바꾸지 않는다.

PTO 위험 시각 참조는 `corrected_rtt + tau(pre_decision_bytes) + c_proc_ms`다. c_proc는 명시 입력이며 기본 추정값을 만들지 않는다. L1의3 ms는 등급 여유이고 독립적인 처리 시간 추정이 아니다. 진단에서는 c_proc0과3을 각각 표시하고, 실제 경계 검증은 J2·J4의 관측과 연결한다.

참조 직렬화는 독립된 `state_version=1`을 쓴다. 이전·미래 판본, 누락·추가 필드, 음수·NaN·무한대, 모순되는 관측 계수와 최솟값을 거부한다. 활성 정책 상태 판본을 바꾼 것으로 해석하지 않는다. 활성 연결 시에는 별도 판본과 Python·Go 거울·기존 전체 W1 관문이 필요하다.

검증은 정확한 바이트를 준 합성 직렬화, 50→100 및50→150 ms 계단, 상승 뒤 하강, 초기값·결측·순서·상태 왕복, 지터와 실제2-RTT 지연의 구분을 포함한다. 감사 원문과 검증자의 수치를 다시 계산한다. 과거 저널의 바이트를 가정해 빼는 값은 근사 재분석으로만 표시한다. 실측 ±1 ms와 전체 W1의0.5 ms 비열등 기준을 단위시험으로 대신하지 않는다.
