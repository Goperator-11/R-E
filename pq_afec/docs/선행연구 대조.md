# 선행연구 대조 — 무엇이 있었고, 우리는 무엇이 새로운가

> 2026-08-14, 5개 영역 병렬 조사(50건 발견 → 41건 정리 → 핵심 원문 정독) +
> 신규성 충돌 표적 재검색. 원자료: 조사 에이전트 보고 (볼트 세션 로그 링크).

## 0. 요약 판정 (정직하게)

**신규성은 성립한다 — 단, 세 가지를 자백한 위에서.**

| 우리 주장 | 판정 | 조건 |
|---|---|---|
| PQC 핸드셰이크 표적 적응형 FEC | ✅ **선행 없음** | 존재하는 모든 QUIC FEC 제안(QUIC-FEC, FlEC, rQUIC, Huawei/Alibaba 드래프트)이 FEC를 0-RTT/1-RTT 레벨로 **명시적 제한** — Initial 보호는 아무도 안 했다 |
| 임계값이 아닌 비용 최소화 이중화 결정 | ⚠️ **QUIC 문헌 안에서는 선행 없음** | 단 **원조는 미디어 도메인**: Bolot 1999(제약 최적화), Boutremans 2003(지연 포함 공동 최적화). 반드시 인용하고 "전송계층 완료시간/PTO 비용으로의 이식"으로 기여를 좁혀야 함. RFC 9265가 이를 미해결 Research Question 1로 남김 — 우리 J(r)은 그 공개 질문에 대한 답 |
| 손실 통계의 연결 간 캐시로 FEC 워밍 | ✅ **선행 없음** | 단 "연결 간 목적지별 캐시"라는 건축 양식 자체는 RFC 2140(1997)→9040→9959(2026)의 표준 계보 — 키 설계는 RFC 9959 §2.2와 동형이라 기여로 못 세움. **캐시 내용(손실률+버스트)과 용도(FEC 워밍)가 기여** |

갭체크(2024~2026 표적 재검색 8회+): **직접 충돌하는 선행 없음.** 웹 전체에서
"핸드셰이크 패킷에 오류정정" 아이디어를 언급한 유일한 문서는 한 백서의
"unconventional but possible mitigation" 한 문장뿐(구현·평가 없음).

## 1. 문헌 지도 (보고서 인용 핵심 15편)

| 영역 | 문헌 | 우리와의 관계 |
|---|---|---|
| QUIC+FEC | **QUIC-FEC** (Michel+, IFIP 2019) | 직계 선행. 이중화는 정적(RS 30,20 고정), "적응은 미래 과제"로 명시. "No FEC frame is sent before the end of the cryptographic handshake" — 핸드셰이크 배제를 문장으로 남김 |
| | **FlEC** (Michel+, ToN 2023) | 가장 가까운 선행. 유스케이스별 임계 휴리스틱(우리는 단일 비용식). "마지막 플라이트만 보호" 발상은 우리 CH 조각 보호와 구조 동형 — 인용 필수 |
| | **rQUIC** (GLOBECOM 2019) | 임계값 곱셈증감(γ=1%, δ=0.33, T=3RTT). **우리 시뮬레이터에 기준선으로 구현됨** — 짧은 연결 최악 후회 129.7% vs 우리 31.5% (시드 12) |
| | **Google QUIC** (SIGCOMM 2017) §7.3 | XOR FEC를 2016년 폐기한 실배포 근거: 손실 에포크의 70%+가 다중 손실이라 r=1 커버율 <30%, 평균 지표에 효과 무의미. → 우리가 배울 것: 평가를 평균이 아닌 **꼬리·최악 후회**로 (우리 설계가 이미 그렇게 함), r을 버스트로 정함(우리 GE-DP가 그것) |
| | **RFC 9265** (IRTF 2022) | "복구된 패킷도 혼잡 관점에선 손실" + "이중화 증가는 소스 전송률 감소와 함께" 권고. 우리 (1+βg) 항과 g-가드의 규범적 근거. 이중화 양 결정을 미해결 질문으로 명시 |
| PQC 배포 | **Cloudflare post-quantum-for-all** (2022) | "1216B Kyber768 키셰어는 ClientHello를 통상 두 패킷으로 분할" — 우리 전제의 1차 출처. QUIC LB가 다중 Initial을 DCID로 못 묶는 문제도 기록 |
| | **Cloudflare pq-2024** (2024) | 실배포 파손율 0.34%(대부분 결정적 실패 — FEC로 못 고침), initcwnd ~10kB 절벽에서 +60% 지연. 서버 인증서 체인이 지배 요인 — **우리가 클라 Initial을 표적하는 범위 논리** |
| | **Benchmarking PQC in TLS** (PQCrypto 2020) | 손실 있는 망에서 큰 PQ 핸드셰이크의 불균형 악화를 처음 정량화. 손실 그리드(0/1/3/5/10%)를 우리 실험 설계에 채택 |
| | **A Quantum of QUIC** (IFIP 2024) | PQC×QUIC 결합 측정의 대표. 무손실에선 Kyber급 영향 작음 → 우리 이득 주장은 **손실 조건부**로 한정할 것 |
| | **quicly #639** (2024) | 서버가 부분 ClientHello를 즉시 ACK하는 실제 구현 — **우리 v0.1 모델의 과장을 잡아준 결정적 출처** (§2 참고) |
| 상태 캐시 | **RFC 2140/9040** (1997/2021) | 연결 간 경로 상태 재사용의 원조·개정. 공유 목록에 손실률/버스트 없음 = 우리 확장점 |
| | **RFC 9959 Careful Resume** (2026) | cwnd/RTT 캐시의 표준화. 키(인터페이스+목적지)가 우리와 동형, Safe Retreat = 우리 "틀려도 콜드 이하" 보장의 표준측 대응물. **손실 통계·FEC 없음** — 우리가 채우는 빈칸의 가장 선명한 증거 |
| | **RFC 9002 §6.2.2** | "같은 네트워크 재개 연결은 이전 srtt를 초기 RTT로 써도 된다(MAY)" — 우리 캐시가 srtt까지 워밍하면 PTO 기저 자체가 작아짐 (v0.2.2에 srtt_ms 파라미터로 반영) |
| 적응 FEC 원조 | **Bolot 1999** (Adaptive FEC for Internet Telephony) | 비용/최적화 기반 이중화 결정의 원조. "임계값 먼저 보여주고 결함 들어 버리는" 서사까지 우리와 동일 — 인용 없이 쓰면 표절 시비급 |
| | **Boutremans 2003** | 지연 비용 포함 공동 최적화 + Gilbert 하 RS 잔여손실 정확 재귀 — 우리 J(r) 구조의 직계 조상. "단일 목적함수가 휴리스틱 결합을 이긴다" 실증은 우리 통일 설계의 정당화 인용 |

(전체 41건 카탈로그·정독 보고 원문: 볼트 세션 로그 참고)

## 2. 선행연구가 우리 모델을 고치게 한 것 (v0.2.2로 반영 완료)

### 정정 1 — "조각 1개 손실 = 무조건 ~999ms"는 과장이었다 🩸

Initial 암호키는 클라이언트 DCID에서 유도되므로 **서버는 ClientHello 조각
하나만 받아도 복호·ACK할 수 있다**(quicly #639에서 구현 확인). 생존 조각의
ACK이 돌아오면 클라이언트는 RTT 표본 + 시간임계 손실 검출을 얻어 **부분
손실의 회복은 ~2RTT**다. ~999ms가 맞는 경우는 ① 플라이트 전멸(버스트가 인접
데이터그램을 같이 삼킴) ② 돌아오는 ACK 손실 ③ 부분 CH를 ACK 안 하는 서버.

**코드 반영**: `expected_handshake_ms`/`simulate_handshake`/`shield`가 실패를
부분실패(2RTT)와 전멸(PTO)로 분리(혼합 비용, `ack_partial` 토글). GE 모델이
전멸 확률을 정확히 주므로 분리가 공짜다. `ack_partial=False`면 v0.1 공식으로
정확히 환원됨을 검증으로 못박음.

**수치 변화 (정직한 재보고)**: 여분 패킷 1개의 핸드셰이크 평균 개선이
v0.1 모델 −19/−25/−33/−40% (p=1/2/5/10%) → **새 모델 −9/−15/−25/−34%.**
이득의 무게중심이 "모든 손실"에서 "버스트 전멸"로 옮겨간다.

### 발견 — 페이싱+FEC 상승작용 (정정 1의 부산물)

K=2 플라이트에 인접 배치된 패리티는 길이 4 버스트가 셋 다 삼키므로 전멸을
거의 못 막는다. 조각들을 몇 ms 간격으로 **페이싱**하면 상관이 끊겨 패리티가
제값을 한다 (p=3%·L=4 실측: 인접 FEC −19%, 페이싱만 −26%, **결합 −49%**;
p=10%에선 결합 **−72%**). v0.1 명세의 "버스트는 이중화로 사지 말고 흩어라"가
핸드셰이크에서 재발견된 것. → 실험 계획 [5]의 quic-go 수정 스펙에 "패리티
추가 + Initial 데이터그램 수 ms 페이싱"을 묶음으로 반영할 것.

### 정정 2 — PTO 999ms는 "첫 접속" 한정 (RFC 9002 §6.2.2)

같은 네트워크의 재개 연결은 이전 srtt를 초기 RTT로 쓸 수 있다(MAY). 서론에서
"조각 손실 → 필연적 1초"로 일반화하면 이 조항으로 반박당한다. **역이용**:
우리 캐시가 손실 통계에 더해 srtt까지 물려주면 PTO 기저 자체가 줄어든다 —
`shield(srtt_ms=...)` 파라미터로 반영, 캐시-srtt 연동은 통합 단계 항목.

### 정정 3 — "혼잡이면 FEC 억제"가 아니라 "비용 가중"

FBRA(2014)는 FEC를 혼잡 구간의 대역 탐침으로 쓰는 게 유익함을 보였다 —
"억제"를 절대칙으로 서술하면 반례가 된다. 우리 실제 메커니즘은 원래
연속 계수 (1+βg) 가중이므로 서술만 통일하면 된다 (문서 표현 정리 완료).

## 4. 가져올 것 (다음 단계, 우선순위순)

1. **손실 에포크 CDF 리포트** (Google Fig.13 방법론): 시뮬·실측에서 "에포크당
   손실 수" 분포와 선택된 r의 커버율을 보고 — "XOR(r=1)은 30% 미만"이라는
   구글 수치와 직접 대비되는 그림.
2. **FEC_ACK 피드백** (Huawei 드래프트): 통합 단계에서 수신자가 "복구된
   손실"을 보고해야 추정기가 잔여손실이 아닌 실손실을 배운다.
3. **캐시 반입 게이트** (RFC 9959 §3.2): 첫 RTT 표본이 캐시 RTT의 1/2 이하
   또는 10배 이상이면 경로 변경으로 보고 사전값 폐기 — 현재 반출측 상한만
   있음. + **원스트라이크 삭제**(급변 확정 시 해당 엔트리 삭제).
4. **DCID 제약 명시**: FEC 이중화 데이터그램은 원본 Initial과 같은 DCID로
   보내야 LB에서 흩어지지 않는다 (Cloudflare LB 문제에서 도출) — 통합 스펙에.
5. **Bolot의 끝-패킷 보호**: CH 마지막 조각의 비대칭 비용(그것 없으면 서버가
   아무것도 못 함)을 r 배치에 반영하는 확장 검토.
6. **DP 문헌 수식 대조 테스트**: Bolot Table 1 / Boutremans 식(11)의 닫힌형과
   우리 P_fail DP를 자동 대조 — "정확 계산" 주장의 문헌적 근거.

## 5. 보고서 문구 가이드

- 신규성 문장 (정확한 버전): "적응형 FEC 자체도(rQUIC 2019~), 비용 기반
  이중화 결정도(Bolot 1999, Boutremans 2003) 선행이 있다. 본 연구의 기여는
  ① 그 결정 이론을 **전송 완료시간/PTO 비용**으로 옮겨 핸드셰이크와 데이터
  구간을 **T_recover 하나로 통일**한 것, ② 모든 기존 QUIC FEC 제안이
  배제해 온 **Initial(ClientHello) 구간**을 표적한 것, ③ 손실 통계의
  **연결 간 캐시**로 짧은 연결과 핸드셰이크 사전값을 워밍한 것이다."
- K=2에서 RS r=1은 XOR 패리티와 동치 — 먼저 자백하고, 구글 XOR 폐기와의
  차이를 "부호가 아니라 결정(언제/몇 개)과 구간(Initial)"으로 명시.
- "FEC는 긴 전송에서 손해" ✗ → "정적 이중화가 긴 전송에서 손해"(QUIC-FEC
  1MB 실측). 적응형은 긴 전송에서도 이득 가능(rQUIC 저널판) — 우리 긴 연결
  후회 6.6%가 그 증거.
- 이득 주장은 **손실 조건부**로: 무손실에선 ML-KEM 영향 자체가 작다
  (A Quantum of QUIC, Chrome 평균 +4%). 우리 무대는 꼬리다.
